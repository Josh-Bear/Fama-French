## ต้องให้ผู้ใช้ตัดสินใจ

1. **เกณฑ์สัดส่วนสัปดาห์ return=0 ต่อ policy** — ข้อมูลจริง: zero_frac สูงสุด E 0.031 / F 0.037 / O 0.012 (ตาราง Q2) · กอง F ที่นี่ไม่ใช่ตลาดเงิน (policy M ถูกตัดโดย 9 เกณฑ์แล้ว) จึงไม่ต้องผ่อนเกณฑ์ให้ F · **เสนอ 0.10 ทุก policy** (ใช้ชั่วคราวใน build นี้ = ตัด 0 class เพราะเกณฑ์นี้) · ถ้าเข้มกว่านี้: เกณฑ์ 0.03 ตัด E3/F2/O0 class · 0.02 ตัด E17/F3/O0 class · ตัวกรองที่มีผลจริงคือเกณฑ์ ≥52 สัปดาห์ + กฎรู NAV 10 วันทำการ (กองที่ NAV ไม่รายวันหลุดตรงนั้น) · ขอให้ยืนยัน/ระบุค่าใหม่
2. **ผลตอบแทนบอนด์ไทย** — ไม่มีราคาบอนด์ จึงเก็บ yield ระดับ + Δyield (ตัวหลัก) และประมาณผลตอบแทนด้วย ret = y₀·days/365 − D_mod(y₀,n)·Δy (D_mod ของ par bond รายครึ่งปี · n = 1/5/10 ปี, T-bill 3M = 0.25 ปี · ไม่มี convexity) ติดป้าย `_est_ret` = ชั่วคราว · ถ้าจะใช้เป็นตัวหลัก ขอให้ยืนยันสูตร/duration หรือเสนอแหล่งดัชนีบอนด์ไทยจริง (ต้องดาวน์โหลดเพิ่ม)
3. **spike ในกอง F ที่ vol ต่ำ** — ใช้ `clean_nav_spikes` ตามบทบาท (แก้ 17 จุด) แต่กฎ F-rule ของ quant_team (M015 §4.2) จับเพิ่มได้ 119 จุด ใน 30 กอง (ถูกใช้เป็น NAV asof ของสัปดาห์ 36 จุด) · ขอให้เลือก: คงตามเดิม (ตรวจอย่างเดียว) / ใช้ F-rule แก้เพิ่มกับกอง F ใน panel
4. **กองที่ return ซ้ำกันข้าม family (corr>0.99)** — 79 คู่ (รายคู่ `dup_pairs.csv`) · ยังไม่ตัด · ขอให้เลือก: คงไว้ทั้งหมด / เหลือ 1 กองต่อกลุ่ม (ตัวที่ประวัติยาวสุด)
5. **class ปันผลที่เป็นตัวแทน family เพราะไม่มี class อื่นผ่านเกณฑ์** — 27 กอง · NAV ไม่รวมปันผล → return ต่ำกว่าจริง · ขอให้เลือก: คงไว้ (ติดป้ายใน universe.csv) / ตัดออก
6. **ปลาย panel 2026** — ใช้ 2026-01 ถึง 2026-07 ดูประกอบเท่านั้น (รูใหญ่ 2026-01-23→2026-01-30; 2026-02-13→2026-03-13; 2026-03-27→2026-04-24; 2026-05-22→2026-06-12; 2026-07-17→2026-07-31) · ยืนยันว่าตัดออกจากการประมาณทุกชั้นตามที่ BRIEF กำหนด
