## 10. G0 — กติกา "factor ต้องครอบสินทรัพย์ของกอง" (ล็อกล่วงหน้า · ไม่ใช่ trial · ใช้กับ R1 / R2 / M1)

## 12. R2 — "correlation จากโมเดล factor ในขั้นเติมกอง" (กระจายความเสี่ยงตาม factor) · ทางเลือก ไม่แนะนำเป็นค่าเริ่มต้น

**นิยาม:**
1. ในขั้นเติมของ `select_sig` แทน `r10.rho_adj_pair` (52 สัปดาห์) ด้วย correlation ระยะยาวจากโมเดล G0:

   ρ_ij = β_i′ Σ_f β_j / √(V_i V_j) · V_i = β_i′ Σ_f β_i + σ²_ε,i

   - β (Dimson · b0 + b1) และ Σ_f (lag 0 · ddof 1) จากหน้าต่าง ≤ t 156 สัปดาห์

**เหตุผล:**
- correlation จากโครงสร้าง factor + หน้าต่างยาวเสถียรกว่า ρ_adj 52 สัปดาห์
- กองกลุ่มเดียวกันจะได้ ρ สูงผ่าน e_g ร่วม (ครอบ R1 แบบนุ่มกว่า)

  - M050: Sharpe ส่วนหนึ่งมาจากโชคปฏิทินการคัดกอง
- มีตัวแปรแฝง (ช่วงค่าของ ρ_model ต่างจาก ρ_adj แต่ DELTA คงเดิม) → **ไม่แนะนำเป็นค่าเริ่มต้น**
