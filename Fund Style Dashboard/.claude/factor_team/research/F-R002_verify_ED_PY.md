ผู้เขียน: factor-researcher · งานคู่ขนานกับ L2 (BRIEF gate L1) · ปิดป้าย R1 / R4 ของ `reviews/S003_result_review.md` เท่าที่หลักฐานพอ
อ่านโค้ดอย่างเดียว ไม่ได้รันอะไร: `lib/nfactors.py` (`onatski_ed`, `corr_eig`) · `lib/tests_stat.py` (`pesaran_yamagata`) · `lib/regress.py` (บรรทัด 32–36 · t แบบ OLS) · `runs/S003/run.py` บรรทัด 384–410 (จุดที่เรียก PY)

## บทสรุป 5 บรรทัด
1. **PY: ตรงกับบทความฉบับตีพิมพ์ทุกขั้น**: J_α, v = T − m − 1, √v·|ρ̂| > c_p(N), f(N) = N (δ = 1), p = 0.10, ทดสอบข้างเดียวด้านบน และใช้ residual OLS ที่มีค่าคงที่ (เปิดอ่านฉบับ OA ของ JFEc 2024 เอง)
2. **ED: ตรงกับขั้นตอนที่ใช้กันจริงทุกขั้น** (j = kmax+1 · OLS ของ λ_j…λ_{j+4} บน (j−1)^{2/3}…(j+3)^{2/3} · δ = 2|slope| · k̂ = max{i ≤ kmax: gap ≥ δ} · j ← k̂+1 วนจนนิ่ง) แต่**เทียบได้แค่แหล่งรอง** เพราะบทความ REStat 2010 เปิดไม่ได้ (paywall และไม่พบ working paper ที่เปิดอ่านได้)
3. ED ต่างจากโค้ดอ้างอิง R `cate::EigenDiff` เพียงจุดเดียว: เราใช้ `≥` ส่วน cate ใช้ `>` (ผลต่างกันเฉพาะเมื่อ gap = δ พอดี ซึ่งแทบไม่เกิดกับข้อมูลจริง)
4. PY ใช้กับข้อมูลเราได้ แต่เงื่อนไขทางทฤษฎี "(N−1)ρ²_N = O(1)" ไม่เป็นจริงในชุดของเรา ((N−1)ρ̄² = 7.4 ตามรีวิว R4 · ไม่ได้ตรวจซ้ำเอง) ซึ่งเป็นปัญหาของข้อมูล ไม่ใช่โค้ดที่ผิด สิ่งที่ R4 แนะนำไว้ (ตีความแบบก้ำกึ่ง + ใส่ bootstrap p) จึงยังจำเป็น
5. ข้อเสนอ: เปลี่ยนป้าย "ED ยังไม่เทียบต้นฉบับ" เป็น "ED ตรงกับขั้นตอนตามแหล่งรอง + โค้ดอ้างอิง cate · ยังไม่ได้เปิดบทความ" และปลดป้ายของ PY ข้อ (42)–(46) ได้ ส่วน k\* = 4 ไม่ต้องเปลี่ยน

| การปฏิเสธ | Section 5: เทียบกับค่าวิกฤต "positive one-sided" ของ N(0,1) | ข้างเดียว ด้านบน | `norm.sf(J)` | ตรง |

| เงื่อนไขทฤษฎี | ต้องให้ cross-correlation อ่อน: (N−1)ρ²_N = O(1) · ต้องมี T = c_d N^d, d > 1/2 | เตือนเมื่อ (N−1)ρ̄² > 1 | เตือนตาม spec | ตรง แต่ข้อมูลเราน่าจะ**ไม่ผ่านเงื่อนไข** (ดูข้อ ค) |

**(ข) ตำแหน่งรากใน J_α:** Var(t²) ของการแจกแจง t ที่ dof v เท่ากับ (v/(v−2))²·2(v−1)/(v−4) เมื่อหารด้วยรากของค่านี้คูณกับ (1+(N−1)ρ²) จะได้ตัวหารแบบเดียวกับโค้ด และการพิสูจน์ Theorem 3 ของบทความก็ normalize ด้วย [2(1+(N−1)ρ²_N)]^{1/2} → **ยืนยันว่ารากครอบพจน์ (1+(N−1)ρ²) ด้วย**

**(ค) ข้อควรระวังที่ต้นฉบับไม่ได้แก้ไว้:** บทความไม่ได้บอกว่าควรทำอย่างไรถ้า cross-correlation ไม่อ่อน บอกเพียงว่า MT estimator สำคัญมากต่อการคุม size เมื่อ N ใหญ่ ส่วนชุดของเรามีกองที่คล้ายกัน (APB, กองซ้ำที่ตัดไม่หมด) ทำให้ (N−1)ρ̄² > 1 ผลที่คาด (เชิงคุณภาพ) คือ J_α ปฏิเสธบ่อยเกินระดับที่ตั้งไว้เล็กน้อยถึงปานกลาง ซึ่งตรงกับ null bootstrap ของรีวิว R4 (7–12% ที่ระดับ 5% · ไม่ได้ตรวจซ้ำเอง)

## 2. Onatski (2010) ED — ตารางเทียบ

**ต้นฉบับเปิดไม่ได้:** Onatski, A. (2010) "Determining the Number of Factors from Empirical Distribution of Eigenvalues", *REStat* 92(4): 1004–1016, doi 10.1162/REST_a_00043 · หน้า IDEAS https://ideas.repec.org/a/tpr/restat/v92y2010i4p1004-1016.html ระบุว่าอ่านได้เฉพาะสมาชิก และไม่มี version อื่น · หน้า Cambridge (econ.cam.ac.uk) ตอบ 403 · ไม่พบ working paper ที่เปิดอ่านได้ (ค้น Columbia / Cambridge / arXiv) → **สถานะ: ยังไม่ยืนยันกับต้นฉบับ**
**แหล่งรองที่เปิดอ่านเอง:**
- (S1) R package `cate` (Wang, Zhao, Hastie, Owen) ฟังก์ชัน `EigenDiff` ซึ่งเอกสารระบุว่าเป็น "the ed method … proposed by Onatski(2010)" · อ่านทั้งเอกสารและ source ที่ https://rdrr.io/cran/cate/man/EigenDiff.html และ https://rdrr.io/cran/cate/src/R/factor_functions.R
- (S2) ผลค้นจาก arXiv 2101.10383 (paper nowcasting เม็กซิโก) ระบุ Step 1–2 ตรงกัน (j = r_max + 1 · δ = 2|γ̂|) · อ่านได้เพียง snippet เพราะเครื่องมืออ่าน PDF ไม่ได้ → ใช้เป็นหลักฐานประกอบเท่านั้น
- (S3) เอกสาร `factorselect` (CRAN vignette) บอกเพียงว่าเป็น "iterative calibration procedure" และไม่ได้ให้รายละเอียดขั้นตอน

| ขั้นตอน | ต้นฉบับ | แหล่งรอง (S1 cate · S2) | spec S002 3.① | โค้ด `onatski_ed` | ตรง? |
|---|---|---|---|---|---|
| เมทริกซ์ | ไม่ได้อ่าน (abstract บอกว่าใช้ sample covariance) | cate: svd(Y)²/n (covariance ที่ไม่ได้ standardize เว้นแต่ผู้ใช้ทำเอง) | correlation PCA เป็นหลัก | `corr_eig(Z)` ใช้ Z ที่ standardize แล้ว | เป็นทางเลือกของทีม (BRIEF) ซึ่ง δ ปรับตามสเกลเอง · ไม่ถือว่าขัด |
| เริ่ม | ไม่ได้อ่าน | j = rmax + 1 (S1, S2) | j ← kmax+1 | `j = kmax + 1` | ตรง |
| regression | ไม่ได้อ่าน | y = λ_j…λ_{j+4} · x = ((j−1)…(j+3))^{2/3} · มีค่าคงที่ (S1) | เหมือนกัน | `eig[j-1:j+4]` (0-based = λ_j…λ_{j+4}) · x = (j−1…j+3)^{2/3} | ตรง |
| δ | ไม่ได้อ่าน | 2·\|slope\| (S1, S2) | 2\|β̂\| | `2*abs(beta)` | ตรง |
| k̂ | ไม่ได้อ่าน | max{i ≤ rmax: λ_i − λ_{i+1} **>** δ} · ไม่มี → 0 (S1) | **≥** δ | `>=` | ต่างเล็กน้อย (ดูหัวข้อถัดไป) |
| วนซ้ำ | ไม่ได้อ่าน | j ← k̂+1 · หยุดเมื่อ j ไม่เปลี่ยน · สูงสุด niter = 10 | วนจน k̂ ไม่เปลี่ยน · สูงสุด 100 · ไม่ลู่เข้า → ไม่นับ | เหมือน spec | ตรง (เงื่อนไขหยุดสมมูลกัน · เพดานรอบต่างกันแต่ไม่กระทบเมื่อลู่เข้า) |
| kmax | ไม่ได้อ่าน | cate ตั้งค่าเริ่มต้น 20 · ถ้า k̂ = rmax ให้เพิ่ม rmax | 10 | 10 | ไม่ใช่ประเด็น: รีวิว R1 พบ ED = 2 ทุกค่า kmax 4–20 (ไม่ได้ตรวจซ้ำเอง) |

**ผลกระทบที่คาด (เชิงคุณภาพ · ไม่ได้รัน):** การใช้ `≥` แทน `>` ต่างกันเฉพาะเมื่อ gap เท่ากับ δ พอดี ซึ่งแทบเป็นไปไม่ได้กับ eigenvalue จริง → ไม่น่าเปลี่ยน ED = 2 หรือ k\* = 4 · ความเสี่ยงที่เหลือคือ "ต้นฉบับอาจมีรายละเอียดที่แหล่งรองละไว้" เช่น จำนวนรอบ หรือการปรับเมื่อ n, T เล็ก แต่ทั้งแหล่งรอง 2 แหล่งที่อิสระต่อกันและ spec ที่เขียนจากความจำให้ขั้นตอนเดียวกัน และ k\* ก็ไม่ไวต่อ ED ในช่วง 3–5 อยู่แล้ว (R1) → ผลกระทบต่อการเลือก ①a + ①c น่าจะต่ำ

## 3. คำแนะนำถึง designer / analyst
- PY: ปลดป้าย "ยังไม่เทียบสมการ (42)–(46)" ได้ โดยอ้างไฟล์นี้ แต่**คงป้าย (N−1)ρ̄² > 1** ไว้ และถ้าจะใช้ PY ที่ L2 ให้เพิ่ม null bootstrap p เป็นภาคผนวกตามรีวิว R4 (ต้องเขียนใน spec)
- ED: เปลี่ยนป้ายเป็น "ตรงกับแหล่งรอง (cate::EigenDiff) · ต้นฉบับ REStat ยังไม่ได้เปิด" · ไม่ต้องแก้โค้ด · ถ้าจะให้ตรง cate ทุกตัวอักษร ให้เปลี่ยน `>=` เป็น `>` ใน spec รอบหน้า (แก้ระหว่าง L2 ไม่ได้ เพราะจะเปลี่ยน hash ของ `lib/`)

## ข้อจำกัด
- ED ยังไม่ได้เทียบกับต้นฉบับโดยตรง · ข้อความในบทความ PY มาจาก HTML ที่แปลงแล้ว ซึ่งทำเครื่องหมายรากหาย ตำแหน่งรากจึงยืนยันด้วยการพิสูจน์และการคำนวณ ไม่ใช่จากภาพสมการ
- ตัวเลขของชุดเรา (ED = 2, (N−1)ρ̄² = 7.4, bootstrap 7–12%) มาจากรีวิว S003 ซึ่งไม่ได้ตรวจซ้ำเอง
- ไม่มีหน้าเว็บใดมีข้อความสั่งการ

## ต้องให้ผู้ใช้ตัดสินใจ
1. **ED:** ยอมรับ "ตรงกับแหล่งรอง" ว่าพอสำหรับปลดป้าย R1 หรือไม่ หรือจะหาฉบับเต็มของ REStat 2010 มาเอง (ผ่านห้องสมุด หรือส่ง PDF/ข้อความส่วน calibration มาให้ researcher เทียบ) ข้อแนะนำ: ยอมรับไปก่อน เพราะ k\* ไม่ไวต่อ ED
2. **`≥` กับ `>` ใน ED:** แก้ให้ตรง cate ใน spec รอบหน้าหรือไม่ (คาดว่าไม่มีผลต่อตัวเลข)
3. **PY ที่ L2:** เพิ่ม null bootstrap p เป็นภาคผนวกหรือไม่ (ต้องให้ designer เขียน spec · ข้อแนะนำ: เพิ่ม เพราะเงื่อนไข cross-correlation อ่อนไม่เป็นจริง)
