## 3. S3 — คำตัดสินกองทอง (BRIEF 116 · แทน S012 ข้อ 8.3 บูลเล็ต O ส่วนทอง และความคาดหมายข้อ 12 / 14 · **เกณฑ์ที่ล็อกไม่เปลี่ยน**)

- **คงเกณฑ์ที่ล็อก (BRIEF 115(4)):** O-X "ดีกว่าตัวเทียบ" ในกลุ่มเมื่อ median ΔR²_oos เทียบตัวเทียบที่ดีที่สุดใน (①a, ①c, ③a) ≥ +0.05 **และ** บวกใน ≥ 2/3 ของกอง · "ตัวเทียบที่ดีที่สุด" = ตัวที่ median R²_oos สูงสุดในกลุ่มนั้น (เลือกด้วยช่วง test · ทิศอนุรักษ์)
- **คำตัดสินบรรยายที่ลงทะเบียนล่วงหน้า (เฉพาะทอง):** "**เทียบเท่า ③a**" เมื่อ |median ΔR²_oos(O-X − ③a)| < 0.02 **และ** median ΔBIC(O-X − ③a) ≤ 0 (บนกองและแถวเดียวกัน) ·
  เหตุผล: `external.line3(F, "3a")` มี `Gold_THB − RF` + FX อยู่แล้ว → span ของ ③a ⊇ span ของ O-X โดยประมาณ (GC=F กับ GLD corr 0.985 · QA_EO §4 ไม่ได้ตรวจซ้ำเอง) + MKT + BOND → O-X ใช้ coefficient น้อยกว่า 4 ตัว
- **ตารางหลักของทอง (ลงทะเบียนล่วงหน้า · `o_gold_tables.csv`):** ต่อกอง + มัธยฐานกลุ่ม (ทั้งหมด · Flag N · Flag Y):
  (1) ΔR²_oos และ ΔBIC ของ O-X เทียบ ③a (คำตัดสิน "เทียบเท่า ③a") · (2) O-X เทียบตัวที่ดีที่สุดของ (①a, ①c) (คำถาม "factor หุ้นพอไหม") — "ดีกว่า factor หุ้น" เมื่อ ≥ +0.05 และบวก ≥ 2/3 ของกอง (ค่าเดียวกับเกณฑ์ที่ล็อก) · (3) O-X เทียบ O-X′ (คุณค่าของการแยก FX · แยก Flag N / Y)
- **ข้อห้ามถ้อยคำ (BRIEF 116):** ห้ามเขียนว่า "ชุดกลไกใช้ไม่ได้กับทอง" จากผล "ไม่ดีกว่า ③a" · ผล "ไม่ดีกว่า" ตามเกณฑ์ที่ล็อกต้องรายงานคู่กับคำตัดสิน "เทียบเท่า ③a" เสมอ
- **ความคาดหมาย (แทน S012 ข้อ 14 และเพิ่มในข้อ 12):** ทอง: ตามเกณฑ์ที่ล็อก O-X "ไม่ดีกว่าตัวเทียบ" (ตัวเทียบที่ดีที่สุดคือ ③a ซึ่งมีทองอยู่แล้ว) · คำตัดสินบรรยาย = "เทียบเท่า ③a" · O-X ดีกว่าตัวที่ดีที่สุดของ (①a, ①c) ≥ +0.20 · O-X − O-X′ ≈ 0 ในกอง Flag Y และ > 0 ในกอง Flag N · REIT: O-X "ดีกว่าตัวเทียบ" (③a ไม่มี REIT · คาดตัวเทียบที่ดีที่สุดคือ ①c)
