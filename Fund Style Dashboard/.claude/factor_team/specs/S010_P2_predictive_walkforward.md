## 3. วิธี — walk-forward (ทุกขั้นใช้ข้อมูล ≤ t ยกเว้นที่ติดป้ายในข้อ 14)

### 3.2 universe ณ t (**ใช้ EVAL ไม่ได้** — EVAL นิยามด้วย ≥ 104 แถวใน train และ ≥ 52 แถวใน test = ข้อมูลทั้งช่วง 2021–2025)

- (u3) สัดส่วนสัปดาห์ที่ r = 0 ในแถว ≤ t ≤ **0.10** (ข้อ 1 แบบ ≤ t)
- (u4) ตัด**กองทอง 6 กอง** (BGOLD · K-GOLD-A(A) · KT-GOLD · SCBGOLDHP · TGOLD · UOBSG-N) และ **`div_flag = Y`** (27 กองใน panel) ออกจาก universe ของ target (ข้อ 93)

### 3.3 expanding PCA (ข้อ 94 · แบบ ①a แต่ประมาณใหม่ทุกไตรมาส)
- **S_t** = กองใน panel (รวมกองทองและ class ปันผล — สอดคล้องกับ ①a) ที่มีผลตอบแทนครบ**ทุกแถว** 2021-01-08 → t และผ่าน (u3) · ตัดซ้ำ ≤ t แบบ (u5) · โครง: 140–149 กองก่อนตัดซ้ำ (≈ 131–140 หลังตัด) · T = 64 → 247 แถว (ไตรมาสแรก N > T: ใช้ได้ เพราะใช้เฉพาะ eigenvector 4 ตัวแรก)
- `pca.pca_fit(R[S_t].loc[:t], k=4, kind="corr")` → Λ_t (N × 4 · `sign_fix`) · μ_t · σ_t (ddof 0) · **k = 4 ตรึง** (ป้าย (ก))
- **factor:** f_s = `pca.factor_returns(R[S_t].loc[s], Λ_t, σ_t, min_frac=0.5)` (ไม่หัก μ · แบบระยะ 1) สำหรับทุก s ≤ t_{q+1} — แถว ≤ t ครบทุกกอง · แถวในไตรมาสเป้าหมายใช้ lstsq บนกองที่มีค่า (normalize เมื่อกองหาย) · **น้ำหนักตรึงที่ Λ_t, σ_t (ไม่ fit ใหม่ใน t+1)**
- **การจัดแนว (เฉพาะ B1 / B2):** orthogonal Procrustes — C = S_t ∩ S_{t−1} · Q_t = UVᵀ จาก SVD ของ Λ_t[C]ᵀ Λ̃_{t−1}[C] · Λ̃_t = Λ_t Q_t (ไตรมาสแรก Λ̃ = Λ) · f̃ = factor จาก Λ̃_t (= Q_tᵀ f เมื่อกองครบ) · ใช้ข้อมูล ≤ t เท่านั้น
- **ข้อเท็จจริงเชิงพีชคณิตที่ test ต้องยืนยัน:** α̂, t(α̂), R², residual, target ปรับ factor และ **B2** ไม่ขึ้นกับการหมุนที่ invertible ใดๆ ของ f (ขึ้นกับ span) · payoff ของ B1 ไม่ขึ้นกับการกลับเครื่องหมาย แต่**ขึ้นกับการหมุน** → การจัดแนวมีผลกับ B1 เท่านั้น (B2 จัดแนวตาม BRIEF แต่ตัวเลขเท่าเดิม)

### 3.4 regression รายกอง ณ t
- **M_PCA:** rᵢ,s = α + b₀′f_s + b₁′f_{s−1} + g₀FX_s + g₁FX_{s−1} + e (11 พารามิเตอร์ · Dimson · `regress.fit_funds` · HAC Bartlett L = 4 ตามระยะ 1) บน s ≤ t ทุกแถวที่มีค่า (expanding ตั้งแต่ 2021-01-15) · ขั้นต่ำ 52 แถว
- **M_3a:** เหมือนกันแต่ factor = MKT · BOND · GOLD · FX ของ `l4.ref3a_factors` (9 พารามิเตอร์)
- **หน้าต่าง 104 (C1):** M_PCA บนแถว index 104 แถวล่าสุด ≤ t (ต้องมี ≥ 52 แถวที่มีค่า) · ถ้า index ≤ t มี < 104 แถว (3 ไตรมาสแรก) → ใช้ทุกแถว ≤ t
- β̂ = b̂₀ + b̂₁ (ผลรวม Dimson) ใช้ใน B2

### 3.5 target (ข้อ 91 · คำนวณ**หลัง**สัญญาณ และด้วยฟังก์ชันแยก)
Wᵢ = สัปดาห์ในไตรมาสเป้าหมายที่ rᵢ, f, FX มีค่า · สเกลด้วย n_q / |Wᵢ| (กองขาดบางสัปดาห์ไม่ถูกเรียงเป็นค่ากลางเพราะผลรวมสั้นกว่า)
- **T_PCA** = (n_q/|Wᵢ|) Σ_{s∈Wᵢ} [rᵢ,s − b̂₀′f_s − b̂₁′f_{s−1} − ĝ₀FX_s − ĝ₁FX_{s−1}] ด้วยค่าสัมประสิทธิ์ของ M_PCA expanding ณ t (**ไม่หัก α̂**) · f_{s−1} ของสัปดาห์แรก = f_t
- **T_3a** = แบบเดียวกันด้วย M_3a · **T_tot** = (n_q/|Wᵢ|) Σ rᵢ,s (ส่วนเกิน RF_BOT)
- ใช้ผลรวมแบบบวก (ไม่ทบต้น) เพื่อให้ T_tot กับ T_PCA อยู่บนสเกลเดียวกัน · rank IC แทบไม่ต่างจากแบบทบต้นในหน้าต่าง 13 สัปดาห์

## 4. ทะเบียน trial (ล็อก · พารามิเตอร์มาตรฐานจากวรรณกรรม · **ห้าม tune** · เปลี่ยนข้อใด = trial ใหม่ = spec ใหม่)

## 5. การทดสอบ — ตัวสถิติ (test ของโค้ดอยู่ข้อ 11.2)

- **IC_q** = `scipy.stats.spearmanr` (อันดับเฉลี่ยเมื่อเสมอ) ระหว่างสัญญาณกับ target บนกองที่มีทั้งคู่ · ไตรมาสที่ N < 30 → NaN · Q_eff = จำนวนไตรมาสที่มีค่า · Q_eff < 12 → trial "N/A (ข้อมูลไม่พอ)" p = 1
- **mean IC** = x̄ · s = sd (ddof 1) = **σ_IC ที่ได้จริง** · SE_iid = s/√Q
- **SE_NW** = √(Ω̂/Q) · Ω̂ = [Q/(Q−1)] (γ̂₀ + 2Σ_{l=1}^{L}(1 − l/(L+1)) γ̂_l) · γ̂_l = Q⁻¹ Σ(x_t − x̄)(x_{t−l} − x̄) · **L = ⌊4(Q/100)^{2/9}⌋** (Newey–West 1994 · = 2 ที่ Q = 15 · 3 ที่ Q = 45) · ที่ L = 0 เท่ากับ SE_iid
- **t_dec** = x̄ / max(SE_iid, SE_NW) (ระวัง: NW ใน T เล็กให้ SE ต่ำเกินได้ — เลือกค่าที่ระวังกว่า · เหตุผลของ designer) · **p = 2·(1 − F_t(|t_dec|; Q_eff − 1))**
- **FM (R1) / Q5−Q1 (R2):** อนุกรม slope / spread → ใช้ t_dec สูตรเดียวกัน
- **B1:** อนุกรม m_q → t_dec สูตรเดียวกัน (ไตรมาสไม่ซ้อน)
- **J1:** เวกเตอร์ slope λ_q (4 ตัว · Q_eff ไตรมาส) → Hotelling T² = Q λ̄′S⁻¹λ̄ → F = (Q−4)/(4(Q−1)) T² ~ F(4, Q−4) (= F(4, 11)) → p เข้า BH
- **ครึ่ง:** x̄_H1 (7 ไตรมาส) · x̄_H2 (8 ไตรมาส) — point estimate ใช้ในกฎข้อ 6 (4)
- σ_IC ที่ได้จริง → **IC_min80 ที่ได้จริง = 1.01 · s** (รายงานคู่ค่าล่วงหน้า)

## 9. DSR ของ IC (ภาคผนวก · ข้อ 96 · ไม่ใช้ตัดสิน)
- ต่อ trial ที่มีอนุกรมตัวตัดสิน x (IC หรือ payoff B1 · คูณด้วยทิศที่ลงทะเบียน): SR̂ = x̄/s ต่อไตรมาส · γ₃ skew · γ₄ kurtosis (ไม่หัก 3) จากอนุกรมเอง (ป้าย "15 จุด · ไม่น่าเชื่อ")
- SR₀ = √V · [(1 − γ)Φ⁻¹(1 − 1/n) + γΦ⁻¹(1 − 1/(n·e))] · γ = 0.5772 · **V = 1/(Q − 1)** (ความแปรปรวนการสุ่มของ SR̂ ใต้ H₀ · ทางเลือกของ designer เพราะ trial ของ quant เป็น Sharpe ของพอร์ต ต่างหน่วย → รวมความแปรปรวนข้าม trial ไม่ได้)
- DSR = Φ((SR̂ − SR₀)√(Q − 1) / √(1 − γ₃SR̂ + (γ₄ − 1)SR̂²/4)) (Bailey–López de Prado 2014)
- n = **20** และ **122** (ข้อ 96) → SR₀ ต่อไตรมาส 0.508 / 0.695 (เทียบเท่า t_iid 1.97 / 2.69) · รายงานเพิ่มด้วย n_combined_A / n_combined_B ที่เกิดจริงตอนจบ (บรรยาย)
- ไม่ได้เทียบโค้ด DSR ของ quant (ต่างหน่วย) · ป้าย "DSR สมมติ trial อิสระ"

## 16. ข้อจำกัด
- **T = 15 ไตรมาส** → ตรวจได้เฉพาะ IC ≳ σ_IC (≈ 0.15–0.25) · ผลส่วนใหญ่ในวรรณกรรมเล็กกว่านี้ → "ไม่ผ่าน" เป็นคำตอบที่คาด
- ช่วง walk-forward ซ้อนกับช่วงที่ใช้เลือกโครงในระยะ 1 (ก) และกับงานของทีม quant (ข) · ไม่มี holdout · ยืนยันได้ด้วย forward test เท่านั้น
- universe / TER / ธงเป็น snapshot (ง)(จ) · cross-section โตจาก ~164 เป็น ~330 กอง → ไตรมาสหลังมีน้ำหนักข้อมูลมากกว่าแต่ IC เฉลี่ยให้น้ำหนักเท่ากันต่อไตรมาส
- D3 ใช้ AUM ของ class ที่เลือก ไม่ใช่ทั้ง family (F-R005 เสนอ family · ไม่มีในข้อมูลทีม)
- FM SE ไม่ทนต่อ correlation ข้ามเวลา (Petersen 2009 · ยังไม่ยืนยันแหล่ง) · ไตรมาสไม่ซ้อนจึงรับได้ · NW ที่ Q 15 ไม่น่าเชื่อ → ใช้ SE ที่ใหญ่กว่า
- permutation ภายในไตรมาสไม่คงโครง factor ข้ามกอง (target ปรับ factor ลดปัญหาได้บางส่วน)
- B1: payoff 4 PC ไม่อิสระจริง · factor ลงทุนไม่ได้ · ช่วงนี้ timing ถูกทีม quant ใช้ไปมาก
- กฎ "ผ่าน" ของรายเดือน / what-if ถูกเลือกตามผลหลัก (กลไกล่วงหน้า แต่ยังเป็น conditional) → ไม่ใช่หลักฐานอิสระ
- ความคาดหมายของทีมคาลิเบรตผิดซ้ำๆ (PHASE1 ข้อ 3)
