## 2. (S2) ตัวกระทบยอด — ล็อกแบบ (ก) "ผลรวมรายสัปดาห์ + บรรทัดผลของการทบต้น"

**นิยาม (ช่วงสรุป S = ชุด anchor ของไตรมาส / ปี / ทั้งช่วง ตามข้อ 1):**
- ผลตอบแทนส่วนเกินรายสัปดาห์: x_s = r_p,s − rf_s (rf_s = `RF_BOT` ของ anchor s) = Σ_k C_k,s + A_s + E_s (เอกลักษณ์ L1 ของ S014)
- **ผลรวมรายสัปดาห์:** SUM_S = Σ_{s∈S} x_s = Σ_k ΣC_k + ΣA + ΣE (บวกกันได้พอดี)
- **ผลตอบแทนส่วนเกินทบต้น (ล็อก):** CEX_S = Π_{s∈S}(1 + r_p,s) − Π_{s∈S}(1 + rf_s) (ไม่ใช้ Π(1 + r_p − rf) − 1)
- **บรรทัด "ผลของการทบต้น":** K_S = CEX_S − SUM_S
- **ตารางทุกช่วงสรุป:** Σ_k ΣC_k + ΣA + ΣE + K_S = CEX_S (test 13 · 1e-12) · รายงาน Π(1 + r_p) − 1 และ Π(1 + rf) − 1 คู่กัน
- K_S ขึ้นกับ r_p และ rf เท่านั้น → **เท่ากันทุกการแยก** (ชุดหลัก · P-A · P-B) ของช่วงเดียวกัน (test 13 ตรวจ)
- ไตรมาสก็ใช้กติกานี้ (K_q ของ 13 สัปดาห์)

**กติกาแสดงผล (ล็อก · ไม่เลือกหลังเห็นผล):**
- หน่วยหลัก = จุด % ของผลตอบแทน (pp) · ทุกตารางที่มีผลรวมต้องมีแถว K_S
- **ส่วนแบ่ง %** แสดงได้แบบเดียว: share_k = ΣC_k / CEX_S โดยมีแถว A · E · K ด้วย (รวม = 100%) · เฉพาะช่วงสรุป ปี / ทั้งช่วง (ไม่แสดงรายไตรมาส) · ถ้า |CEX_S| < 2 pp → "N/A ฐานเล็ก"
- ห้ามเขียน "% ที่มาของผลตอบแทนทบต้น" ที่ไม่มีแถว K ในตารางเดียวกัน · ห้ามใช้ Carino / log linking (ไม่ลงทะเบียน)

**L2 (กติกาเดียวกัน):**
- รายไตรมาส: R_q^off,ex = `ret_gross` − rf_q^off (ข้อ 4.3) = Σ_k B_k,q F_k,q + A_q + ε_L2,q · F_k,q = Σ_{s∈q} f_k,s (ผลรวมรายสัปดาห์ช่วงถือข้อ 1)
- **ε_L2 รวมส่วนต่างการทบต้น** (ผลทางการทบต้นรายวัน vs F บวกรายสัปดาห์) + เวลา (start / end_mis) + น้ำหนักลอย (B ใช้ w ต้นไตรมาส) + ขอบ lag ของ b1 + class / hedge + ε เฉพาะตัว + ต่างนิยาม rf — ระบุใน results.md · แสดง K_q ของ L1 และ Δ_q ของ reconcile คู่กันเพื่ออ่าน
- หลายไตรมาส: SUM^off_S = Σ_q R_q^off,ex · CEX^off_S = Π_q(1 + `ret_gross`_q) − Π_q(1 + rf_q^off) · K^off_S = CEX^off_S − SUM^off_S · ΣBF + ΣA + Σε_L2 + K^off_S = CEX^off_S (test 13)

**ภาคผนวก:** P-A / P-B ใช้กติกา L1 เดียวกัน · P-C ข้อ 4.2
