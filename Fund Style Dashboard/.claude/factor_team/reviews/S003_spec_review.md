## สิ่งที่ designer ฝากดู

### 1. test 18 (tolerance 5e-5 · พารามิเตอร์จำลอง) — **รับได้**
- โครง: x_i = MKT − FX_SHV + e_i เป็นเชิงเส้นแม่นตรงใน regressor → α = 0, β_MKT = 1, β_FX = −1 แม่นตรง (ก) · กรณี (ข) x = MKT − (1+r_US)·s + (r_TH − r_US) + e → α = −0.0005 แม่นตรง β_FX = −1.0009 (อยู่ในช่วงที่ตรวจ)
- ขนาด noise ของ mean α̂: regressor ชุดเดียวกันทุกกอง → mean_i α̂_i = α̂ ของ mean_i e · sd ≈ 0.002/√200/√155 × √(1 + μ̄'Ω̂⁻¹μ̄) ≈ 1.1e-5 (Sharpe รายสัปดาห์ของ regressor ≈ 0.05 → ตัวคูณ ≈ 1.005) → tolerance 5e-5 ≈ 4.4 sd (ผ่านแน่ภายใต้ seed ตายตัว) · ระยะห่าง (ก)/(ข) = 5e-4 = 10 เท่าของ tolerance → test แยกสองนิยามได้ชัด
- median β: SE ต่อกองของ b0+b1 ≈ 0.011 (MKT) / 0.024 (FX) → ช่วง ±0.05 กว้างพอสำหรับ median ของ 200 กอง
- พารามิเตอร์สมจริง: carry 0.0005/สัปดาห์ ≈ 2.6%/ปี ใกล้ปี 2023–25 · sd(s) 0.011 ตรง QA_L0 · ข้อสังเกต (ไม่บังคับ): carry คงที่ทำให้ FX_SHV เป็น affine ของ s → test พิสูจน์ได้เฉพาะเรื่อง intercept (ซึ่งคือประเด็นของ N1) · ถ้าอยากครอบกรณีจริงที่ carry กลับเครื่องหมาย (2021–22 r_US < r_TH) ให้ใช้ r_US เป็นขั้นบันได 2 ระดับ แล้วตรวจ (ก) ซ้ำ — ไม่จำเป็นต่อการรัน

### 2. เกณฑ์ (ข) ของธง nonFX_eq — **รับได้ (ค่าชั่วคราวข้อ 21 ยืนยันแล้ว)** · ข้อสังเกตอยู่ใน M3

### 3. bootstrap CI ของ r\* อาจ N/A — **รับได้ แต่ระบุกติกาเพิ่ม** (M2 · ไม่บล็อก เพราะเป็นภาคผนวก)

### 4. ตัวเลขที่ไม่ได้ตรวจซ้ำ — ตรวจแล้วตรงทั้ง 3 ชุด (ดูหัวข้อข้อเท็จจริง) · ให้ลบคำว่า "ไม่ได้ตรวจซ้ำเอง" แล้วอ้างรีวิวนี้ได้

## ปัญหาใหม่จาก addendum (ทั้งหมดเล็กน้อย — analyst ทำได้โดยไม่ต้องเดา หรือเป็นภาคผนวก)

### M1 — เล็กน้อย · ข้อความ "NaN ของ MSCI รายเดือน ไม่กระทบช่วงประมาณ" ไม่ถูกทั้งหมด
- NaN อยู่ที่ 2021-01-31 ใน **MSCI ทั้ง 28 ตัว** · Dimson ของแถว 2021-02-28 ใช้ lag = 2021-01-31 → รูปแบบรายเดือนที่มี MSCI (③a/③b/④a + การจัดภูมิภาครายเดือนถ้ามี) **เสียแถว 2021-02 เพิ่มอีก 1 แถว** เทียบกับ ①/② ที่ factor มีค่าตั้งแต่แถวแรก · เกิดตั้งแต่ S002 (ไม่ได้เกิดจาก N1) และเป็นแค่ตรวจซ้ำรายเดือน
- แก้: ให้ analyst รายงานจำนวนแถว train รายเดือนต่อรูปแบบ (หรือใช้ชุดเดือนร่วมกันทุกรูปแบบ) · เกณฑ์ ≥ 24 เดือนยังผ่าน

### M2 — เล็กน้อย · bootstrap CI ของ r\* เมื่อมีรอบ N/A
- percentile จากรอบที่ rel ≥ 0.10 เท่านั้นเป็น CI **แบบมีเงื่อนไข** (เอียงไปทาง rel ใหญ่) · ถ้าสัดส่วน N/A สูง CI ไม่มีความหมาย
- ข้อเสนอ (ล็อกก่อนรัน): r\* จุดเป็น N/A → ไม่คำนวณ CI · `r_star_na_frac` > 0.10 → `r_star_lo/hi` = "N/A (noise ครอบงำ)" · 0 < na_frac ≤ 0.10 → รายงาน CI พร้อมป้าย "เงื่อนไขบน rel ≥ 0.10" · ไม่มีผลต่อเกณฑ์ (ข้อ 18)

### M3 — เล็กน้อย · ธง nonFX_eq: ระบุเพิ่ม 2 จุด + ข้อจำกัด 2 ข้อ
- (ระบุ 1) กองที่ถูกย้ายไปเรียงในกลุ่ม ACWI (เพราะกลุ่มเดิมเหลือกองไม่มีธง < 10): **FX beta และ 1 − R² ยังคำนวณด้วยดัชนีตามป้ายภูมิภาคเดิมใน `regions.csv`** (ย้ายเฉพาะกลุ่มเรียง) — ตีความได้จาก "ป้ายไม่เปลี่ยน" แต่ควรเขียนตรงๆ และใส่ใน test 19
- (ระบุ 2) ใน split-half (S002 4.2 ข) เกณฑ์ "กองไม่มีธง < 10 → ACWI" **นับภายในครึ่ง** (สอดคล้องกับ "เกณฑ์กลุ่ม < 10 นับในครึ่ง A" ของ S002) · ธงต่อกองใช้ค่าเดิม
- (ข้อจำกัด ก) 8 ดัชนีของข้อ 1 ไม่มี `MSCI_ASEAN` (มีในข้อมูล) → กองหุ้น ASEAN / อินโดนีเซีย (เช่น KT-ASEAN-A, ES-INDONESIA, ASP-ASIAN ตามชื่อ) อาจมี R² ต่อ TDEX สูงกว่าดัชนีทั้ง 8 แล้วได้ธง (ข) ทั้งที่เป็นหุ้นต่างประเทศจริง · ผลกระทบไม่กี่กองในการเรียง FXH ที่ขาละ ≈ 30% ของ ~200 กอง · ไม่เปลี่ยนเกณฑ์ (ข้อ 21) แต่ใน `run_log.md` ให้ระบุว่ากองที่ได้ธง (ข) จาก TDEX มีชื่อส่อหุ้นต่างประเทศกี่กอง
- (ข้อจำกัด ข) กองมีธงยังถูกแบ่งพอร์ต GRS hedge/ไม่ hedge ด้วย FX beta (ตามข้อ 21) ทั้งที่เหตุผลของ N4 คือ FX beta ของกองเหล่านี้ไม่ใช่อัตรา hedge → เขียนเป็นข้อจำกัดของพอร์ต GRS (ไม่ต้องแก้)
