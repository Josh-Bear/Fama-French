- **วิธีแก้:** เขียนข้อ 3.② ใหม่: **②b = ②a + FXH (K=4)** · **②c = ②b + MOM + SIZE + ACT (K=7)** · train ของ ②c = 2022-01-14 → 2023-12-29 (103 แถว) · ชุดกองใช้ EVAL หลัก (207 กอง กำหนดจาก train เต็ม) โดยกำหนดขั้นต่ำของ ②c เป็น **≥ 78 แถว** ใน 2022–23 (ผ่านทั้ง 207 กอง ตามที่ตรวจ) · H1 ของ ②c = 2022-01-14 → 2023-06-30 หรือรายงาน "N/A" (เลือกแล้วล็อก) · rolling ใช้เฉพาะหน้าต่างที่เริ่ม ≥ 2022-01-14 · GRS train T = 103 · MOM รายเดือน = ทบต้นผลตอบแทนรายสัปดาห์ของขาในเดือนนั้น หรือ N/A · ลบแถว P0 ในข้อ 2.1 และในนิยาม MOM · ใส่ป้าย "ไม่เทียบตรง (ค่าชั่วคราวข้อ 8)" ทุกที่ที่ ②c อยู่ในตารางคะแนน · ปรับ H②b ให้ตรงกับ ②b ชุดใหม่ (ตอนนี้ตรงอยู่แล้ว: FXH เทียบ ②a)

### R2 — ร้ายแรง · α ของสาย ① ไม่ใช่ pricing error (factor ถูกทำให้ค่าเฉลี่ยเป็นศูนย์)
- **สถานการณ์:** ①a ใช้ z = (x − μ_i)/σ_i ส่วน ①b ใช้ d = x − μ_i แล้วตั้ง f_t = Λ'z_t → ใน balanced train ค่าเฉลี่ยของ f เท่ากับ 0 ทุกตัว ทำให้ α̂_i = ค่าเฉลี่ย excess return ของกอง ดังนั้นคะแนนข้อ 3 ของ ① (mean|α̂|, GRS train, PY train) **จะวัดได้แค่ว่าผลตอบแทนเฉลี่ยเป็นศูนย์ไหม** เอาไปเทียบกับ ③ ไม่ได้ (ใน ③ factor เป็นผลตอบแทนส่วนเกินจริง) · ใน test ค่าเฉลี่ยของ f = Λ'(μ_test − μ_train)/σ ซึ่งไม่มีความหมายทางเศรษฐศาสตร์ · R² ไม่กระทบเพราะต่างกันแค่ค่าคงที่
- **วิธีแก้:** คำนวณ eigen จากข้อมูลที่หักค่าเฉลี่ยออก (เหมือนเดิม) แต่สร้าง **factor return เป็นพอร์ตจากผลตอบแทนที่ไม่หักค่าเฉลี่ย**: ①a f_t = (Λ_A'Λ_A)⁻¹Λ_A'(x_A,t/σ_A) · ①b ใช้ x_A,t · ①c แบบเดียวกัน (σ จากแถวที่มีค่า) · ใช้นิยามเดียวกันในทุกช่วงเวลา · test ข้อ 5 ปรับตามนี้
- **④a (สำคัญ · หลักการเดียวกัน):** ê_test = x − α̂ − β̂'f ทำให้ residual PC ในช่วง test มีค่าเฉลี่ยเท่ากับ α_test − α̂_train ที่ถ่วงด้วย loading → PC ดูด α ของช่วง test ไป → GRS/PY ของ ④a ในช่วง test มีแนวโน้มไม่ปฏิเสธเกินจริง · **แก้:** น้ำหนักยังมาจาก PCA ของ ê ช่วง train เหมือนเดิม แต่ factor return ทุกช่วง = น้ำหนัก × (x − β̂'f) โดย**ไม่หัก α̂** (ได้พอร์ตที่ hedge แล้วและลงทุนได้)

### R3 — สำคัญ · สูตร Pesaran–Yamagata ไม่ตรงกับต้นฉบับ 3 จุด
แหล่งที่ใช้ตรวจ: หน้าบทความที่ academic.oup.com (JFEc 22(2) 407, สมการ 42–46 และ 61–64) ดึงผ่าน WebFetch · **ข้อความที่ดึงมาไม่มีเครื่องหมายราก/เส้นเศษส่วน สูตรจึงถูกประกอบกลับ — ยังไม่ได้ยืนยันทุกตัวอักษร** · PDF ของ White Rose ดาวน์โหลดได้แต่ในเครื่องไม่มีโปรแกรมอ่าน PDF
1. **เกณฑ์ threshold:** ต้นฉบับใช้ c_p(N) = Φ⁻¹(1 − p/(2f(N))) โดย **f(N) = N^δ และใช้ δ = 1 (f(N) = N)** ทั้งใน simulation และงาน empirical · spec ใช้ f(N) = N(N−1)/2 ซึ่งเข้มกว่า → ρ̄² เล็กลง → ตัวส่วนเล็กลง → **ปฏิเสธเกินจริง** เมื่อ residual ของกองสัมพันธ์กัน (ซึ่งน่าจะเป็นแบบนั้น: feeder เข้า master เดียวกันที่ corr 0.95–0.99 ยังอยู่ในชุด)
2. **ตัวคูณในเงื่อนไข:** ต้นฉบับเป็น I[|√v·ρ̂_ij| > c_p(N)] (ในข้อความที่ดึงได้เห็นเป็น "v ρ̂" ซึ่งน่าจะเพราะเครื่องหมายรากหาย) · spec ใช้ √T_ij → analyst ต้องเปิดดูสมการ 42/63 ก่อนเขียนโค้ด
3. **panel ไม่สมดุล:** ต้นฉบับใช้ T และ v = T − m − 1 ตัวเดียวทุกหลักทรัพย์ (ต้องมี v > 4 · ต้องให้ N/T² → 0) · การใช้ v_i ของแต่ละกอง + ρ จากคู่ที่ทับกันใน spec เป็น**ส่วนขยายที่ไม่มีในต้นฉบับ** และไม่มีทฤษฎีรองรับ
- ตัวเศษกับรูปตัวส่วนแบบ balanced ใน spec (N^{-1/2}Σ(t² − v/(v−2)) / sqrt((v/(v−2))²·2(v−1)/(v−4)·(1+(N−1)ρ̄²))) ตรงกับต้นฉบับ · p = 0.10 รับได้ (ต้นฉบับบอกว่าผลไม่ไวต่อ p ในช่วง 1–10%)
- **วิธีแก้:** (ก) ให้ f(N) = N · (ข) ตัวคูณตามสมการ 42 · (ค) **ฉบับหลัก = ตามต้นฉบับ** ใช้กอง EVAL ที่มีครบทุกแถวในหน้าต่างนั้น (train 148 กอง / test 206 กอง) · ฉบับขยาย v_i เป็น sensitivity · (ง) รายงาน ρ̄² และ (N−1)ρ̄² · ถ้า (N−1)ρ̄² ≫ 1 ให้บอกว่าเงื่อนไข "cross-correlation อ่อน" น่าจะไม่เป็นจริง · (จ) test ข้อ 10 ต้องเพิ่มกรณีที่ error สัมพันธ์กันแบบ block (ไม่ใช่อิสระอย่างเดียว) ให้คล้ายกลุ่มกองซ้ำ

### R4 — สำคัญ · สาย ②: GRS เป็น circular และ |α| วัดเทียบกับกองในกลุ่มเดียวกัน (ตอบคำถามของ designer ข้อ 2)
- ให้ PY เป็นตัวหลักของ ② **ได้** เพราะ t_i แต่ละตัวมาจาก factor LOO ของกองนั้น และ PY ไม่ต้องใช้ factor ชุดเดียวทุก test asset · แต่ยังมีอีก 2 เรื่อง:
  1. APB_E คือค่าเฉลี่ยถ่วงเท่ากันของกอง E ชุดเดียวกัน → α ของ ② คือ "α เทียบกับกองในกลุ่ม" ซึ่งค่าเฉลี่ยข้ามกองถูกบังคับให้ใกล้ 0 · ดังนั้น mean|α̂| ของ ② **เทียบกับ ③ ไม่ได้** (③ เทียบกับดัชนีที่ลงทุนได้) → ให้รายงาน signed mean α ด้วย และติดป้าย "peer-relative"
  2. GRS ของ ②: แทนที่จะติดป้ายอย่างเดียว เสนอแบบ **แบ่งกองครึ่ง**: สุ่มแบ่งฐาน 277 กองเป็น 2 ครึ่งด้วย seed 20261015 · สร้าง factor ② จากครึ่ง A · พอร์ต GRS จากครึ่ง B (และสลับกัน) → ได้ GRS ที่ไม่ circular · ถ้าไม่ทำ ให้ตัด ② ออกจากการเรียงลำดับด้วย GRS (ใช้แค่บรรยาย)
- **ต้องระบุเพิ่ม (ใช้กับทุกสาย):** GRS/PY ในช่วง test fit α, β ใหม่ในช่วง test โดยใช้อนุกรม factor ที่สร้างจากน้ำหนัก train — ใช่หรือไม่ · spec ยังไม่ได้เขียน (analyst ต้องเดา) · Ω̂ ใช้ MLE (หาร T) ให้ตรงกับรูป F ที่แม่นตรง

### R5 — สำคัญ · ความเสถียรแบบครึ่งละ 130 สัปดาห์: noise ของการประมาณกับจำนวนพารามิเตอร์ปนกัน (ตอบข้อ 3 และ 6 ของ designer)

- **วิธีแก้:** (ก) ใช้**ชุดกองเดียวกันทุกรูปแบบ**ในข้อ 5 (เสนอ ≥ 104 แถวต่อครึ่ง = 191 กอง: E159/F18/O14) · (ข) รายงาน corr ของ β ต่อ factor ร่วม (MKT/PC1/APB_E) แยกจากค่าเฉลี่ยทุก factor · (ค) รายงานคู่กับค่าคาดหมายภายใต้ "β คงที่" (เช่น split-half ภายในครึ่งเดียวกันแบบ สัปดาห์คู่/คี่ หรือปรับด้วย reliability = var(β̂) − mean(SE²)) เพื่อแยก noise ออกจากการเปลี่ยนจริง · ③c ในตัวมันเอง: ใน train มี dof ≥ 65 และ GRS test มี dof 46 → **รันได้** · power ต่ำเป็นข้อจำกัดที่รับได้ ไม่ต้องตัดออก

### R6 — สำคัญ · จุดกำกวมอื่นที่ analyst ต้องเดา
1. ED (Onatski 2010) เขียนว่า "ตามบทความ" — ต้องเขียนขั้นตอนลงไป (จากความจำ **ยังไม่ยืนยันแหล่ง**: δ = 2|slope| จาก OLS ของ λ_j บน (j−1)^{2/3}, j = k+1…k+5 · k̂ = max{i ≤ kmax : λ_i − λ_{i+1} ≥ δ} · วนจน k คงที่) หรือให้ analyst เทียบกับบทความแล้วบันทึกไว้
2. การกำหนดภูมิภาค: กอง E ที่ไม่ใช่หุ้น (ทอง/REIT/โครงสร้างพื้นฐาน ถ้ามี) จะถูกบังคับให้อยู่ในภูมิภาคที่ R² ต่ำ → ให้ใส่กฎ "max R² < 0.3 → 'อื่น'" (หรือค่าที่ล็อกไว้) · ใช้กฎรวมกลุ่มเดียวกันใน FXH (< 10 → อื่น) และ GRS (< 5 → ACWI) หรือเขียนเหตุผลว่าทำไมต่างกัน · ลำดับงาน: `regions.csv` และสมาชิกพอร์ต GRS ต้องเขียนลงไฟล์**ก่อน** fit รูปแบบใด
3. ① แยก "ใน/นอก sample PCA": นอก sample มีแค่ E67/F3/O5 · สำหรับ ①c ฐาน 277 ครอบเกือบทั้ง EVAL → แทบไม่มีกลุ่มนอก sample → spec ต้องบอกว่า F/O และ ①c รายงานเป็น "n ไม่พอ" · เสนอให้ใช้กลุ่มนอก sample ของ E เป็นตัวเทียบหลักของ ① กับสายอื่นในคะแนนข้อ 1–2
