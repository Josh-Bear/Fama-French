## B. ตรวจข้อโต้แย้งเรื่อง residualize (ข้อ 3.4 · H3.4)

**ข้อสรุป: designer ถูก**
- design ของกอง (Dimson) = [1, f_t, f_{t−1}, I_t, I_{t−1}] · แทน I ด้วย e = I − b̂′f (b̂ ตรึงจาก train ใช้ทุก t) → [1, f_t, f_{t−1}, I_t − b̂′f_t, I_{t−1} − b̂′f_{t−1}] = design เดิมคูณเมทริกซ์ A ที่หาอินเวอร์สได้และ**เหมือนกันทุกแถว** → fitted, residual, R², R²_oos, BIC เท่าเดิม
- เพราะ e **ไม่หัก â** คอลัมน์ค่าคงที่ไม่ถูกผสม → A = diag(1, A₂₂) → α̂ และ**ความแปรปรวน HAC ของ α̂** เท่าเดิม (t_HAC, BH ของ α ไม่เปลี่ยน) · GRS ไม่เปลี่ยนเช่นกัน (μ′Ω⁻¹μ ไม่แปรเมื่อแปลงเชิงเส้นแบบไม่เลื่อนค่าเฉลี่ย) · PY ใช้ residual เดิม
- ถ้าหัก â: R² เท่าเดิมแต่ α เปลี่ยนเป็น α + (b0 + b1)·â ตรงตามที่ spec เขียน
- **แบบ F-R004 (a + b′f_t + c′f_{t−1}):** e_{t−1} พา f_{t−2} เข้ามา ซึ่งไม่อยู่ใน design → **span เปลี่ยนจริง** (และ α เปลี่ยนด้วยถ้าหัก a) · ข้อความใน F-R004 L3-1 ที่ว่า "α ไม่เปลี่ยน" ถูกเฉพาะกรณีที่ e เก็บค่าคงที่ไว้ — spec แก้ให้ถูกแล้ว
- ข้อมูลจำลอง (`span_sim.py` · T 260 · train 155 · HAC L = 4) — ส่วนต่างเทียบกับดัชนีดิบ:

| แบบ | Δα | Δt_HAC(α) | ΔR² | ΔR²_oos |
|---|---|---|---|---|
| lag 0 · เก็บค่าคงที่ (spec) | 2e-17 | 3e-14 | 0 | 1e-16 |
| lag 0 · หัก â | +1.22e-3 (= (b0+b1)·â ตรงทุกหลัก) | +1.66 | 0 | 1e-16 |
| F-R004 (a + b f_t + c f_{t−1}) | +1.21e-3 | +1.65 | **+9.2e-5** | **−2.0e-5** |
| F-R004 แต่เก็บ a | −3.4e-5 | −0.06 | **+9.2e-5** | **−2.0e-5** |

**ข้อแม้ที่ต้องเขียนในรายงานผล:** ความเท่ากันนี้ถือเมื่อ**แม่ทุกตัว (P_j) อยู่ใน design ของกอง** — จริงสำหรับ B (P = f อยู่ทุก design) และ C closure (iii) · **ไม่จริงสำหรับ C-blk / C-prim เมื่อแม่ที่ไม่ใช่ MKT ไม่ได้อยู่ในบล็อก** (เช่น e_THD ถูกเลือกโดยไม่มี ASEAN / ASIA_EX_JAPAN) → แถว C ไม่ใช่ "C0 + ดัชนีดิบ" · spec ติดป้ายไว้แล้ว ("ไม่บังคับให้แม่ต้องอยู่ในบล็อกก่อนลูก") แต่ผลต้องไม่อ้าง H3.4 กับแถว C · และ B-all ≡ f + **ดัชนีดิบ P4 ทั้ง 6 ตัว** ทุกตัวชี้ที่ไม่ใช่ coefficient รายตัว / SE / VIF (m11)

## C. ปัญหาของ spec (ร้ายแรง 0 · สำคัญ 0 · เล็กน้อย 12)

**m1 — เกณฑ์หยุดของ A1 ตีความได้ 2 แบบเมื่อ f มี VIF ≥ 5 (เล็กน้อย · ต้องบันทึกก่อนรัน)**
ข้อความ "ถ้าเหลือแต่ f ที่ VIF ≥ 5 → หยุดและติดป้าย" อ่านได้ว่า (ก) หยุดเมื่อคอลัมน์ที่ VIF ≥ 5 เหลือแต่ f (ดัชนีทุกตัว < 5) หรือ (ข) ตัดดัชนีไปเรื่อยจนทุกคอลัมน์รวม f < 5 (ตรงกับ BRIEF "ชุดรวม (factor + ดัชนี) VIF < 5" มากกว่า) · สถานการณ์นี้เป็นไปได้จริง: adj R² ของ PC ①a บน M28 = 0.843 / 0.911 / 0.502 / 0.813 (`results.md` §8 ข้อ 8.3) บ่งชี้ VIF ของ PC1/2/4 ราว 5–11 ก่อนตัด (เป็นการประมาณจากตัวเลขที่รายงาน M28 ≠ C11+S10 · ไม่ได้คำนวณใหม่) และ C11 มี China A + H ที่ใกล้ปริภูมิ PC2 · ผลต่าง: S_A, A-prim (R1/R6), Q1a-A และ Q3(b) · test 31 ข้อ "ผลลัพธ์ VIF < thr" ขัดกับแบบ (ก)
**ข้อเสนอ:** ใช้ (ก) เป็นหลัก (ตรงกับถ้อยคำและหลัก "f ห้ามตัด") · **เดิน log ต่อเชิงบรรยาย**จนทุกคอลัมน์ < 5 แล้วรายงานชุดแบบ (ข) ใน `vif_elim_A.csv` และ A-mem (ไม่ fit แถวคะแนนเพิ่ม) · เพิ่มกรณีใน test 31: คอลัมน์ protect มี VIF ≥ 5 ขณะที่ดัชนีทุกตัว < 5 → หยุด + ป้าย

**m2 — Q1a(i) ใช้สถิติเดียวกับที่เลือก P4 (designer ถาม · เล็กน้อย)**
P4 ผ่านเพราะ median ΔR²_oos ช่วง test ในกองหลัก ≥ 0.02 · Q1a(i) วัด drop-one ΔR²_oos ในกองเดียวกัน ช่วงเดียวกัน → **แทบถูกกำหนดล่วงหน้า** สำหรับดัชนีที่ L2 สูงกว่าเกณฑ์มาก (HC 0.38/0.45 · India 0.19/0.47 · Vietnam ①a 0.30) · (iii) ผ่านโดยโครงสร้าง (e ⟂ f ใน train) · ช่องทางเดียวที่ทำให้ Q1a ตกได้จริงคือ **collinearity ระหว่างดัชนีใน P4 ด้วยกัน** + ΔBIC (train) · ผลกระทบต่อข้อสรุปจำกัด เพราะ Q1 ถามเรื่อง collinearity ไม่ได้ถามเรื่องหลักฐานนอกช่วงใหม่ และ spec ติดป้ายไว้ใน §10 แล้ว
**ข้อเสนอ:** (1) เพิ่มประโยคใน §7 "อ่าน": "Q1a ผ่าน = ส่วนเพิ่มของ j ยังอยู่เมื่ออยู่ร่วมกับ f และ P4 อีก 5 ตัว — **ไม่ใช่หลักฐานนอกช่วงใหม่**" + คอลัมน์ `evidence_independent = False` ใน `q1_verdict.csv` (2) (ไม่บังคับ · บรรยาย) drop-one แบบ pseudo-OOS ภายใน train (fit 2021-01-08 → 2022-06-24 · วัด 2022-07-01 → 2023-12-29) ในกองหลักของ j — ช่วงนี้ไม่ได้ใช้ตัดสิน P1(ข) จึงเอียงน้อยกว่า (ต้องให้ผู้ใช้ตัดสินใจ ข้อ 2)

**m3 — ลำดับชั้น / cap 8 / กฎ τ (designer ถาม · เล็กน้อย)**

**ข้อเสนอ:** เมื่อหยุด (เพราะ τ หรือ cap) ให้ `select_C.csv` บันทึก score ดีที่สุดของ**รอบถัดไป**ด้วย (ผู้ใช้เห็นว่า cap ผูกมัดไหม) · ป้ายชื่อ: Vietnam ไม่ได้เป็นสมาชิก MSCI AC Asia ex Japan → e_VIETNAM อ่านว่า "เกินจาก AxJ" ได้ แต่ไม่ใช่ "ประเทศในภูมิภาค" ตามองค์ประกอบดัชนี

**m4 — fallback B-all′ ไม่ได้นิยาม drop-one / Q1a (เล็กน้อย · ต้องบันทึกก่อนรัน)**

**m5 — Wald ใน B-all ยืมกฎ placebo ของ L2 (designer ถาม · เล็กน้อย)**
