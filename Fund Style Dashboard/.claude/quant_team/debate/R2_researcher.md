## ไอเดีย 2 — BAND5: no-trade band สำหรับกองที่ถือต่อ
**อัลกอริทึม ณ t** (หลังได้ target `w_T` ของ M024 ทั้งพอร์ต — หุ้น + ทอง + ตลาดเงิน)
```
w_prev = น้ำหนักเป้าของ plan ไตรมาสก่อน (e_prev) · drift ด้วย NAV ≤ t:  w_d(i) ∝ w_prev(i) · NAV_i(t) / NAV_i(e_prev)   (Σ = 1)
F = { i : i ∈ w_T และ i ∈ w_d และ |w_T(i) − w_d(i)| ≤ 0.05 }          # กองที่ถือต่อและห่างเป้าไม่เกิน 5 pt ของพอร์ต
T = กองอื่นทั้งหมดใน w_T (ใหม่ หรือห่าง > 5 pt)
w_new(i) = w_d(i)                                   สำหรับ i ∈ F
w_new(i) = w_T(i) · (1 − Σ_F w_d) / Σ_T w_T         สำหรับ i ∈ T        # ถ้า T ว่าง → w_new = w_d (ไม่ซื้อขาย)
```
- ข้อมูล ≤ t (NAV ถึง t · ไม่ใช้ NAV ณ e) · การคัดกอง/ERC/GC ไม่เปลี่ยน → **ไม่แตะเส้นทาง** (กฎถือต่อใช้ชุดกองที่ถือ ไม่ใช่น้ำหนัก)
- พารามิเตอร์ค่าเดียว: **5 pt** = เกณฑ์มาตรฐานที่ Vanguard (Jaconetti, Kinniry & Zilbering 2010) สรุปว่าสมดุลระหว่างคุมความเสี่ยงกับต้นทุน · ไม่จูน
  · GC เปลี่ยน x ทีละ 25 pt → การพลิกหุ้น↔ทองเกิน band เสมอ (สัญญาณยังทำงาน) · band ตัดเฉพาะ "ERC ขยับนิดหน่อย" ซึ่งเป็น noise ของ Σ 52 สัปดาห์
- **ผลที่คาด**: ลดถัง (ข) ใน D · สัดส่วนหุ้นจริงเพี้ยนจาก x_t ได้ไม่เกิน ~5 pt (ต้องรายงาน max) · Sharpe +0.01–0.03 · offset ทุกตัวได้ทิศเดียวกัน
- **ความเสี่ยง**: sim ยังซื้อขายเล็กน้อยจาก drift 2 วัน (t → e) — รายงาน turnover ที่เหลือ · Vanguard ศึกษาพอร์ตหุ้น/บอนด์กว้าง ไม่ใช่ 3 กอง → หลักฐานเรื่อง "ค่า 5" เป็นธรรมเนียม ไม่ใช่ค่าที่เหมาะที่สุด
- **regression**: band = 0 → `w_new = w_T` ทุกบิต → M024

- พารามิเตอร์ค่าเดียว: 50% = "สินทรัพย์เดี่ยวไม่เกินครึ่งพอร์ต" (ตั้งก่อนดูผล · ไม่ใช่ค่าจาก grid)
- **เหตุผล**: k = 0 = ทุก horizon ของหุ้นโลกติดลบ = ภาวะ risk-off ที่ absolute momentum แบบดั้งเดิม (Antonacci; Faber) ไปอยู่ T-bill ไม่ใช่สินทรัพย์เสี่ยงอีกตัว ·
  ทอง vol ~15% → ถือ 75% ทำให้ vol พอร์ตในไตรมาสที่ตั้งใจจะ "หลบ" ไม่ต่ำจริง · Baur & Lucey (2010, อ้างใน R1): ทองเป็น safe haven สั้น (~15 วันทำการ) ไม่ใช่รายไตรมาส
- **ผลที่คาด**: vol/MaxDD ปี 2022 ลด · ผลตอบแทน 2022 H2 เปลี่ยนตามทอง THB ช่วงนั้น (ทิศไม่แน่) · CAGR แทบไม่กระทบ (2023–2025 ไม่มี k = 0 ใน offset 0 — `M013_signals.csv`) · คาดผลเล็ก ±0.03
- เทียบ "ทอง+ตลาดเงิน 50/50 ตลอด" (ที่ supervisor ยกมา): **ไม่แนะนำ** — ตัดทองครึ่งหนึ่งในปี 2025 ที่เป็นตัวสร้าง CAGR (M019 y2025 31.8% vs M020 ขาตลาดเงิน 22.9%) → CAGR ลด ~1.5%/ปี และ Sharpe น่าจะอยู่ระหว่าง M020 (0.92) กับ M024 · GCAP50 คือรูปที่ตัดเฉพาะส่วนที่กระจุกเกิน
- **regression**: cap = 1.0 → M024 ทุกบิต

## ไอเดีย 5 — STACK2: ซ้อนเฉพาะคันโยกที่ไม่แตะเส้นทาง (ลงทะเบียนล่วงหน้า)
- กติกา: รวม X ∈ {GLEG-S หรือ GLEG, BAND5, GCM, GCAP50} ถ้า X เดี่ยวได้ **Sharpe ≥ 1.171 (M024) และ เฉลี่ย offset ≥ 1.0** · GLEG กับ GLEG-S เลือกได้ตัวเดียว (ตัวที่ผ่าน ถ้าผ่านทั้งคู่ใช้ **GLEG-S** — ตัดส่วน post-hoc ทิ้ง)
- ลำดับประกอบ: เลือกกองหุ้น (M024) → GC/ทอง (GLEG, GCAP50) → แทรกเดือน (GCM) → band (BAND5 ทำบนรายการไตรมาส **และ** รายการ GCM — รายการ GCM เป็นการลดหุ้นทั้งก้อนจึงเกิน band อยู่แล้ว)
- เหตุผลที่คาดว่าบวกกันได้ (ต่างจาก STACK รอบ 1): ทั้ง 4 ตัวไม่เปลี่ยน `held`/อันดับ/ตัวเติม → ชุดกองหุ้นทุกไตรมาส = M024 ทุกบิต (ต้อง assert) · ผลจึงมาจากต้นทุนและสัดส่วน ไม่ใช่เส้นทางใหม่
- regression: ปิดทุกตัว = M024 · เปิดทีละตัว = X เดี่ยวทุกบิต · **assert ชุดกองหุ้นต่อไตรมาส = M024**
- ความเสี่ยง: ถ้าแต่ละตัวได้ +0.01–0.02 รวมกัน +0.03–0.07 → ผ่านข้อ 1 แบบหวุดหวิด ซึ่งยังอยู่ใน noise — **รายงาน nofront และรายปีคู่เสมอ** ให้ผู้ใช้เห็นว่าผ่านเพราะต้นทุน ไม่ใช่โชคเส้นทาง
