### R4-1 SMOOTH3 — เฉลี่ย breadth 3 สิ้นเดือน (tranche ของสัญญาณ)
```
ms = fs.month_end_points(cal, t, 3)                 # ms[-1] = t · assert
b̄  = mean( canary_b(m) for m in ms )               # canary_b เดิมทุกบรรทัด (EM THB + บอนด์ D=6 · 13612W) · แต่ละตัวใช้ข้อมูล ≤ m ≤ t
x  = max(0.25, min(GC75[k_t], 1 − b̄/2))             # ค่า b̄ ∈ {0, ⅓, ⅔, …, 2} → x ต่อเนื่อง
```
- พารามิเตอร์ **3 = จำนวนเดือนในไตรมาส = จำนวน offset** (โครงสร้าง ไม่ใช่การจูน): เทียบเท่าแบ่งการตัดสินใจ canary เป็น 3 tranche รายเดือน
  (Hoffstein: rebalance timing luck แก้ด้วยการ "ปรับทีละน้อยแต่บ่อย" · Zarattini & Pagani 2025: timing luck ลดราว 1/N ตามจำนวน tranche)
- ไม่เพิ่มการซื้อขาย (ยังเปลี่ยน x เฉพาะวัน rebalance รายไตรมาส · BAND5 เดิม)
- ผลต่อ x (ตรวจแล้ว): 2024-12-31 → 0.333 (เดิม 0.25 → เก็บ Q1'25 ได้ ~83%) · offset 1 2025-01-31 → 0.333 (เดิม 0.5) · offset 2 2025-02-28 → 0.50 (เดิม 0.75)
  · แต่ก็ลดหุ้นเพิ่มใน 2023-09/12, 2024-03/06 (x 0.67–0.83) = **ทองมากขึ้นในปี 2024** (ส่วนบวกของ proxy นอก Q1'25 มาจากตรงนี้)
- คาด: ข้อ 1 ≈ M036 (−0.03 ถึง +0.03) · ข้อ 2 +0.02 ถึง +0.06 · ข้อ 3 ± (off1 ขึ้น off2 ลง) · regression: ms = [t] (ไม่มีการเฉลี่ย) → M036

### R4-2 ENSDEF — b ต่อเนื่องจาก 4 นิยาม (ไม่ผูกกับ lookback/สกุลเงินเดียว)
```
EM_THB = lv["MSCI_EM"] · EM_USD = EM_THB / USDTHB (MACRO_FACTOR วันเดียวกัน asof ≤ m) · BND = L เดิม (USD)
f ∈ { 13612W (สูตรเดิม), SMA13: z12 / mean(z0..z12) − 1 }   # 13 จุดสิ้นเดือนเดิม
b_ens = mean over f × {EM_THB, EM_USD} ของ [1{f(EM) ≤ 0} + 1{f(BND) ≤ 0}]    # ∈ {0, ¼, …, 2}
x = max(0.25, min(GC75[k_t], 1 − b_ens/2))
```
- เหตุผล: 13612W = ตัวกรอง canary ของ VAA/DAA/BAA · SMA13 (ราคา/ค่าเฉลี่ย 13 เดือน) = ตัวกรองที่ BAA ใช้กับสินทรัพย์รุก (CXO สรุป Keller 2022)
  · การเฉลี่ยหลาย lookback เป็นแนวมาตรฐานของ trend (Hurst, Ooi & Pedersen: เฉลี่ยเท่ากัน 1/3/12 เดือน) · THB กับ USD: ไม่มีเหตุผลก่อนดูผลที่จะเลือกตัวใดตัวหนึ่ง → เฉลี่ย
- ณ 2024-12-31 ทั้ง 4 แบบ = 2 → **x เดิม 0.25 (ข้อ 1 ไม่เสีย)** · ต่างจาก M036 ส่วนใหญ่ในปี 2023 (b ครึ่งทาง เช่น 2023-06 x 0.75 แทน 0.5) และ 2024-01/04 offset 1–2
- คาด: ข้อ 1 ≈ (±0.03) · ข้อ 2 ≈ (±0.02) · ข้อ 3 −0.00 ถึง −0.05 · **คุณค่าหลัก = พิสูจน์ว่าผล M036 ไม่ได้ขึ้นกับนิยาม** · regression: f = {13612W}, สกุล = {THB} → M036

### R4-3 VOTE — GC75 กับ canary โหวตเฉลี่ย แทน "เสียงที่ป้องกันกว่าชนะ"

## 4. คำแนะนำถึง modeler
1. **D0 ก่อน** (0 trial) — ถ้า M041 ข้อ 2 ≥ 1.3 แจ้งผู้ใช้ก่อนว่าผ่านแล้ว
2. รัน R4-1, R4-2, R4-3 บนฐาน M036 (3 trial) + R4-7 STACK4 (1) + R4-6 sensitivity (1) = **5 trial** · R4-4/R4-5 ถ้าเหลืองบ (ผมคาดว่าลบ)
3. ประมาณการตรงๆ: โอกาสมีแบบผ่านทั้ง 3 ข้อ ≈ **35–50%** (ส่วนใหญ่ผ่าน STACK4/M041 เพราะข้อ 2 เฉียดเส้น) · โอกาสที่ผ่านด้วยกลไกที่ไม่พึ่งทองบูม 2024–25 ≈ **≤ 15%**

## 5. ต้องให้ผู้ใช้ตัดสินใจ
