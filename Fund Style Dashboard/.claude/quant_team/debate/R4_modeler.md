**2.1 อัลกอริทึม** (ใน `make_xfun.xf(qi, t, kt)` แทนบรรทัด `b = ...` และ `x = ...` · ข้อมูลทุกตัว ≤ m ≤ t):

def b_at(m):                                   # m = จุดสิ้นเดือน (trading day) ≤ t
    if not cfg.ens: return canary_b(m)         # เดิมทุกบรรทัด
    ms = fs.month_end_points(cal, m, 13); assert ms[-1] <= m and len(ms) == 13
    emT = [lv["MSCI_EM"].loc[:mi].dropna().iloc[-1] for mi in ms]
    fx  = [mac["USDTHB"].loc[:mi].dropna().iloc[-1] for mi in ms];  emU = emT / fx
    L   = บอนด์สังเคราะห์เดิม (US10Y, D = 6) บน ms เดียวกัน
    mom = 13612W เดิม ; sma(z) = z[12] / mean(z[0..12]) − 1
    return mean([ int(f(e) <= 0) + int(f(L) <= 0)  for f in (mom, sma) for e in (emT, emU) ])   # ∈ {0, ¼, …, 2}
ms_s = fs.month_end_points(cal, t, cfg.smooth); assert ms_s[-1] == t and len(ms_s) == cfg.smooth
b̄  = mean(b_at(m) for m in ms_s)               # smooth = 1 → b_at(t)
T  = T_table[kt] * m_VSL                         # m_VSL = 1 ถ้า vsl ปิด (เดิม)
xc = 1 − b̄/2  if cfg.canary else 1.0
x  = max(0.25, min(T, (T + xc)/2)) if cfg.vote else max(0.25, min(T, xc))
olog: เพิ่ม b_bar, x_base = max(0.25, T)

## 5. ต้องให้ผู้ใช้ตัดสินใจ
1. **D0 พบแล้วว่า M041 ข้อ 2 = 1.292 (ขาด 0.008)** — ถ้าผู้ใช้ยอม "เกือบ" ก็ไม่ต้องรันรอบนี้ · ถ้าต้องการผ่านจริง M046 คือทางหลัก
