## 1. โต้แย้งทีละไอเดีย
### D3 FRONTIER — **เห็นด้วย (0 trial) แต่แก้ตรรกะการตัดสิน**
- สูตร √[(S_S² + S_G² − 2ρS_SS_G)/(1−ρ²)] ถูกสำหรับ tangency **ไม่มีข้อจำกัด** — ต้องเพิ่ม long-only + หุ้น ≥ 25% (กติกาผู้ใช้) ไม่งั้น w* อาจติดลบ
- **ไม่ใช่ขอบบนของแบบที่จับจังหวะ**: M033 เองเปลี่ยน x ตาม GC (timing) · CAP75/RB2/VSL/CANARY ก็ timing → "ส่วนผสมคงที่ดีที่สุด < 1.4" **ไม่ได้พิสูจน์** ว่าไอเดีย 2–3 ไปไม่ถึง
- ใช้แทน: (ก) Sharpe ส่วนผสมคงที่ดีที่สุด (ภายใต้ข้อจำกัด) · (ข) **มูลค่าของ timing** = Sharpe(M033) − Sharpe(ส่วนผสมคงที่ที่ x̄ ของ M033) → บอกว่าความหวังอยู่ที่ "ส่วนผสม" หรือ "จังหวะ"
- **ไม่ใช้กั้นการรัน** (ทุกแบบถูก · ผู้ใช้ขอให้ลองหลายแบบ) — ใช้อธิบายผล

- m(L) = [12(L₁₂/L₁₁−1) + 4(L₁₂/L₉−1) + 2(L₁₂/L₆−1) + (L₁₂/L₀−1)]/4 (index 0..12 = ms) · b = #{m(EM) ≤ 0, m(บอนด์) ≤ 0}
- `xfun = max(0.25, min(GC75[k], 1 − b/2))` · ปิด = b ≡ 0

**M037-RB2** (overlay · **SENSITIVITY ไม่เข้า STACK**) · σ_S จาก M034 · σ_G = std(`QuarterContext(GD.arrays, cal, t).weekly_return_series(g)`, ddof=1)·√52
(g = กองใน `GS[k][qi][0]` · สัปดาห์ valid < 40 หรือไม่มีทอง → x = GC75[k]) · `xfun = max(0.25, min(GC75[k], σ_G/(σ_S+σ_G)))`

**M038-NH52** (signal · แตะเส้นทาง) · ต่อ family ใน `reps` (ก่อนสลับ class): f = rep FundCode · (d, v) = `e_arr[f]` · หน้าต่าง W = {t − 364 วัน < d ≤ t}
- |W| < 200 → NaN · NH = `fs._asof(d, v, t)` / max(v[W]) · score = ½·pctrank(SR12) + ½·pctrank(NH) (pctrank = `Series.rank(pct=True)` ข้าม reps · NH NaN → score = pctrank(SR12))
- รายงาน: จำนวน rep ที่ NAV มีวันลด > 5% ในวันเดียวใน W (ตัวแทน XD)

**M039-RESID** (signal · แตะเส้นทาง) · r = `ctx["wk"][f]` · a = ACWI weekly (กริดเดียวกัน) · a₋₁ = a.shift(1)
- แถวที่ r, a, a₋₁ ไม่ NaN ≥ 40 · OLS ไม่มีค่าคงที่ r = b0·a + b1·a₋₁ (`np.linalg.lstsq`) · u = r − b0·a − b1·a₋₁ (บนแถว valid)
- RS12 = Σ u (ตัด 4 สัปดาห์ล่าสุดของกริด) / (std(u, ddof=1)·√n_used) · score = pctrank(RS12) (RS12 NaN → pctrank(SR12) ของ family นั้น)

**M040-FIP** (signal · แตะเส้นทาง) · NAV รายวันของ rep ใน (t − 365 วัน, t − 30 วัน] · ผลตอบแทนรายวันระหว่างจุด NAV ติดกัน (n ≥ 150 ไม่งั้น NaN)
- PRET = NAV_asof(t−30)/NAV_asof(t−365) − 1 · ID = sgn(PRET)·(#ลบ − #บวก)/n · score = ½·pctrank(SR12) + ½·pctrank(−ID) (ID NaN → pctrank(SR12))

**M041-STACK (ลงทะเบียนล่วงหน้า · ≤ 1 trial)**
- overlay {VSL, CAP75, CANARY} ผ่านถ้า: Sharpe > 1.204004 **และ** off_mean ≥ 1.0 **และ** `sh_exQ222`(X) ≥ `sh_exQ222`(M033)
- signal {NH52, RESID, FIP} ผ่านถ้า: Sharpe > 1.204004 **และ** off_mean ≥ 1.0798 (= M033 · กัน path luck offset เดียว)
- RB2 ไม่มีสิทธิ์ · ผ่าน ≥ 2 ตัว → รัน M041: score = ค่าเฉลี่ยเท่ากันของ pctrank {SR12} ∪ {NH, RS12, −ID ที่ผ่าน}
  · `xfun = max(0.25, min(T[k]·m_VSL, 1 − b/2))` (T = CAP75 ถ้าผ่าน ไม่งั้น GC75 · m_VSL = min(1, σ_A/σ_S) ถ้าผ่าน ไม่งั้น 1 · b ≡ 0 ถ้า CANARY ไม่ผ่าน)
  · regression: STACK ที่เปิดส่วนประกอบเดียว = แบบเดี่ยวนั้นทุกบิต (ตรวจทุกตัวที่ผ่าน) · ผ่าน 1 ตัว = ตัวนั้นคือผล · 0 ตัว = ไม่รัน
- ตัวสุดท้ายของรอบ = ผู้สมัครที่ Sharpe > 1.4 · หลายตัว → ส่วนประกอบน้อยกว่า (ไม่เลือกตาม Sharpe สูงสุด) · ไม่มี → รายงานตัวสูงสุดพร้อมป้ายทั้งหมด
