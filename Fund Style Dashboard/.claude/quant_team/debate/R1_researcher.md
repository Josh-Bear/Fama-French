## ไอเดีย 1 — TR3: tranche 3 ก้อน (แบบคำนวณง่าย = รวม 3 พอร์ตย่อยที่มีอยู่แล้ว)
**อัลกอริทึม (ข้อมูล ≤ t ทุกจุด)**
```
ทุน 1 แบ่งเป็น 3 พอร์ตย่อย j ∈ {0,1,2} ก้อนละ 1/3
เริ่มต้น: ทั้ง 3 ก้อนใช้ plan ของ M019 offset 0 ณ t0 = 2022-03-31 (ซื้อวันทำการที่ 2 เหมือนเดิม)
หลังจากนั้น ก้อน j ใช้ plan ของ M019 offset j ทุกรายการที่ t > t0
   (ก้อน 0: มี.ค./มิ.ย./ก.ย./ธ.ค. · ก้อน 1: เม.ย./ก.ค./ต.ค./ม.ค. · ก้อน 2: พ.ค./ส.ค./พ.ย./ก.พ.)
   · state ของ hysteresis/ถือต่อ = ของ stream offset j เอง (stream_lc ของ offset j ทำไว้แล้ว)
จำลองแต่ละก้อนด้วย sim เดิม (Fee3 จริง · ค่าธรรมเนียมเป็น % จึงแยกก้อนได้ถูกต้องเท่ากับพอร์ตรวม) ด้วยปฏิทินเดือน E["months"] ของ offset 0
V(m) = V0(m) + V1(m) + V2(m) → ผลตอบแทนรายเดือน → Sharpe/CAGR/MaxDD ตามปกติ (45 เดือน)
offset test ของ TR3: offset k = ทั้ง 3 ก้อนเริ่มจาก plan offset k ณ ต้นงวดของ offset k (ที่เหลือเหมือนกัน) → คาดว่าทั้ง 3 ค่าใกล้กันมาก
```
- implement: `plan_j = [plan_off0[0]] + [p for p in plan_offj if p["t"] > t0]` แล้ว `sim(plan_j)` 3 ครั้ง · ปรับค่าเริ่ม 1/3 (หรือรวมค่าดัชนีแต่ละก้อนเท่ากันแล้วหาร 3 — เทียบเท่ากันเพราะทุกก้อนเริ่มวันเดียวกันที่ค่า 1)
- ตัวแปรเสริม (ถ้า sim รวมไม่สะดวก) **TR3-NET**: พอร์ตเดียว ตัดสินใจทุกสิ้นเดือน m: w_new = (2/3)·w_drift + (1/3)·T_m โดย T_m = เป้าของ stream offset (m mod 3) ·
  = "ซื้อขายทีละน้อยแต่บ่อย" (Gârleanu & Pedersen 2013: เดินเข้าหาเป้าทีละส่วน) · ใกล้เคียง TR3 แต่น้ำหนักเป้าเก่าลดแบบ exponential
- พารามิเตอร์: จำนวนก้อน = 3 (= ความยาวไตรมาส · ไม่ใช่ตัวเลือก) · ฐาน = M019 ทุกบิต
- **ช่วยเป้าข้อไหน**: ข้อ 2 โดยกลไก — พอร์ตเดียวกันไม่ขึ้นกับเดือนเริ่ม (ส่วนต่าง offset เหลือแค่ plan แรก) · ข้อ 1 ผ่าน 2 ทาง: (ก) 2/3 ของพอร์ตตัดสินใจใหม่ได้สิ้น เม.ย./พ.ค. 2022 แทนที่จะรอ มิ.ย. (ไตรมาสแรกคือตัวลากข้อ 1)
  (ข) การกระจายข้ามเวลาลด vol ของพอร์ตรวม (3 ก้อนสัมพันธ์กันไม่เต็มร้อย) → Sharpe รวม ≥ ค่าเฉลี่ย Sharpe ของ 3 offset ได้
- **หลักฐาน (แข็ง)**: Hoffstein, Faber & Braun (2020) — ดัชนี factor long-only ในสหรัฐฯ มี rebalance timing luck มักเกิน 100 bp/ปี และ momentum สูงสุด (1–4%/ปี; พอร์ต 100 หุ้น rebalance ครึ่งปี ~4.4%/ปี) · ผลยิ่งแรงเมื่อ **พอร์ตกระจุก + rebalance ห่าง** (= M019: 3 กอง รายไตรมาส) · ทางแก้ที่เสนอคือ tranching
  · Zarattini & Pagani (2025, Quantpedia สรุป) — momentum สหรัฐฯ 1991–2024 ช่องว่าง CAGR ระหว่างตารางวันดีสุด/แย่สุด ~348 bp · timing luck ลดลงตาม 1/N ของจำนวนก้อน **ขณะที่ผลตอบแทนเฉลี่ยคงเดิม**
  · Maymin, Maymin & Fisher (SSRN 1899000) — time-series momentum บน futures ไวต่อวันเริ่ม แม้ข้อมูลหลายทศวรรษ และเกิดได้แม้ใน return จำลอง iid → เป็นคุณสมบัติของ momentum ไม่ใช่ความผิดปกติของข้อมูลเรา
- **ความเสี่ยง**: (1) Zarattini & Pagani: นักลงทุนรายย่อยได้ประโยชน์น้อยเพราะต้นทุนคงที่ต่อครั้ง — **ของเราค่าธรรมเนียมเป็น % ไม่มีค่าคงที่ต่อครั้ง** จึงไม่โดน แต่มีขั้นต่ำการซื้อของกอง (ไม่ได้จำลอง) ·
  (2) โดยกลไก TR3 จะ **ไม่** ได้ 1.47 ของ offset 0 ในช่วงร่วม — คาดว่าอยู่แถวค่าเฉลี่ย (~1.0 ช่วงร่วม) บวกโบนัสกระจาย → ข้อ 1 น่าจะยังไม่ผ่านถ้าใช้ TR3 อย่างเดียว · (3) จำนวนกองที่ถือรวมได้ถึง 9 กอง + ขาทอง/ตลาดเงิน (ไม่ผิดกติกา 4–10 แต่ดูแลยากขึ้น)

## ไอเดีย 2 — SM3: เฉลี่ยสัญญาณ 3 สิ้นเดือน (rebalance รายไตรมาสเท่าเดิม ไม่เพิ่มรอบซื้อขาย)

## ไอเดีย 3 — FEE0: เติมกองแบบรู้ค่าธรรมเนียมขาเข้า (ไม่แตะอันดับ — ต่างจาก M009)
**อัลกอริทึม** (แทนเฉพาะบรรทัด "เลือก c ที่ score ต่ำสุด" ใน M019 §2)
```

s* = min score(c) ;  C = { c ∈ P \ S : score(c) ≤ s* + 0.10 }
เลือก c ∈ C ที่ cost(c) ต่ำสุด · เสมอ → score ต่ำกว่า → อันดับ SR12′ ดีกว่า
```

- **หลักฐาน (ปานกลาง)**: เป็นกลไกบัญชี (ค่าธรรมเนียมที่ไม่จ่าย = ผลตอบแทนที่ได้แน่นอน) · M009 ล้มเพราะหักค่าธรรมเนียมใน **อันดับ** (ดันกองอันดับดีออก) — ที่นี่ใช้เฉพาะในกลุ่มตัวเติมที่ "เกือบเสมอกัน" ด้าน correlation และยังอยู่ใน pool ≤ 9 ·
  R005 (ทีม): front-end มักถูกยกเว้นในทางปฏิบัติ — ถ้าจริง Sharpe nofront คือขอบบน
- **ความเสี่ยง**: กองค่าธรรมเนียม 0 อาจกระจุกบาง บลจ. / class ที่มีเงื่อนไข · ตาราง FF ก่อน snapshot แรกใช้ snapshot เก่าสุด (look-ahead อ่อน — ต้องรายงานจำนวนครั้ง) · กระทบเฉพาะไตรมาสที่มีการเติม (M019 เติม 1–3 กอง/ไตรมาส)

## ไอเดีย 4 — MH: คะแนนกองหลาย horizon (แทน SR12′ ในขั้นจัดอันดับ)
**อัลกอริทึม ณ t**
```
สำหรับ L ∈ {3, 6, 12} เดือน (จุดสิ้นเดือนจาก fs.month_end_points · NAV ≤ t):
   SR_L(f) = (R_L(f) − h_L) / vol52(f)        # h_L = rf จริงทบช่วงเดียวกัน (r11.hurdle) · vol52 ตัวเดิม
   (L = 12 ใช้ R12-1 ตามนิยาม SR12′ เดิม · L = 3, 6 ไม่ข้ามเดือน)
MH(f) = (SR_3 + SR_6 + SR_12) / 3   → แทน SR12′ ทั้งในการเลือก class ตัวแทนและอันดับ family · อื่นเหมือน M019
```
- พารามิเตอร์: {3, 6, 12} น้ำหนักเท่ากัน — ชุดเดียวกับสัญญาณ GC75 ที่ทีมใช้อยู่ (ไม่ใช่ค่าใหม่) · ไม่ใช้ 1 เดือน (fund NAV รายเดือนสั้นมี noise/reversal และ R001 ชี้ว่าสัญญาณสั้นแลกด้วย turnover)
- **ช่วยเป้าข้อไหน**: ข้อ 1 — ตามธีมใหม่เร็วขึ้น (ธีมกองไทยเปลี่ยนเร็ว: เวียดนาม → infra → ญี่ปุ่น/ยุโรป → อินเดีย → ทอง/การเงิน ใน 15 ไตรมาส ตาม `M019_quarters.csv`) · ข้อ 2 — คะแนนที่เฉลี่ยหลาย horizon เปลี่ยนช้ากว่าเมื่อเทียบกับการเลื่อนหน้าต่าง 1 เดือนของ R3 เดี่ยว และลดน้ำหนักของ "เดือนที่ตกจากหน้าต่าง 12 เดือน"
- **หลักฐาน (ปานกลาง)**: Levine & Pedersen (2016, FAJ) — TSMOM กับ MA crossover เทียบเท่ากันในรูปทั่วไป และการรวมหลาย horizon เป็นตัวกรองทั่วไปที่ใช้ได้ (สรุปจาก PDF ที่เปิด — ตัวเลขเฉพาะยังไม่ยืนยัน) ·
  Keller & Keuning (2017, VAA) ใช้ momentum เฉลี่ย 1/3/6/12 เดือน (13612W) กับ asset class 12 ตัว นอกตัวอย่าง 1993–2016 (CXO สรุป: CAGR > 10%, DD < 15% · CXO เตือน data snooping + ต้นทุน ETF จำลอง) — ระดับ asset class ไม่ใช่กองหุ้น
- **ความเสี่ยง**: turnover เพิ่ม (SR_3 เปลี่ยนเร็ว) → front-end เพิ่ม · hysteresis pool 9 ช่วยกันได้บางส่วน · กองใหม่ที่ R3 แรงช่วงสั้น (ข่าว/ธีมร้อน) เข้ามาง่ายขึ้น · ทีมยังไม่เคยลองสัญญาณอื่นนอกจาก SR12 ในโครง LC3 → path luck สูง

## ไอเดีย 5 — DEFX: ขาไม่ใช่หุ้น = กอง O/F ที่ momentum ดีที่สุด (แทนกองทองตายตัว)
**อัลกอริทึม ณ t** (ส่วน 1 − x_t)
```
D_t = กอง policy O (ทุกชื่อ ไม่จำกัด GOLD) + policy F ที่ไม่ใช่กองตลาดเงิน — ผ่านกติกาข้อมูล/คุณภาพเดียวกับ GData (≥ 252 NAVDate, สด ≤ 10 วัน, AUM_fam ≥ 100 ล้าน, อายุ ≥ 730 วัน, retail, ไม่ใช่ class ภาษี)
ตัดกองที่ ρ_adj(f, MSCI ACWI THB) 52 สัปดาห์ > 0.5     # ต้องเป็นขาที่ไม่ใช่หุ้นจริง (REIT/infra/น้ำมันที่ตามหุ้นถูกตัด)
class ตัวแทนต่อ family = SR12′ สูงสุด (กติกาเดิม)
เลือก 1 กองที่ SR12′ สูงสุดใน D_t ถ้า SR12′ > 0 · ไม่มี → กองตลาดเงิน (กติกา M015-FAUM)
```
- ความยาก: ง่าย (GData กรอง "GOLD" ในชื่ออยู่ — แก้เป็นกติกาข้างบน · FeeData O/F แยกอยู่แล้ว · ρ_adj ใช้ `run_m010.rho_adj_pair` กับ ACWI รายสัปดาห์)
- พารามิเตอร์: เพดาน ρ 0.5 (ค่ากลาง "สัมพันธ์ปานกลาง" ตั้งก่อนเห็นผล) · 1 กอง (ลดต้นทุน)
- **ช่วยเป้าข้อไหน**: ข้อ 1 (CAGR) — ทองตายตัวติดลบปี 2022 (brief) · กติกา absolute momentum + เลือกตัวดีสุดในฝั่งตั้งรับ = ให้ขากันมีโอกาสถือสิ่งที่กำลังขึ้น หรือกลับไปตลาดเงินเมื่อไม่มีอะไรขึ้น
- **หลักฐาน (ปานกลาง–อ่อน)**: Antonacci (dual momentum, SSRN 2042750 — ทีมอ้างใน R003) และ VAA/DAA (Keller & Keuning) เลือกสินทรัพย์ตั้งรับด้วย momentum แทนการถือตายตัว · Baur & Lucey (2010) — ทองเป็น hedge ต่อหุ้นโดยเฉลี่ย และ safe haven ช่วงหุ้นร่วงรุนแรง **แต่ผลอยู่สั้น (~15 วันทำการ)** → การถือทองตายตัวในฐานะ "ประกัน" ระยะไตรมาสมีหลักฐานอ่อนกว่าที่คิด
- **ความเสี่ยง**: (1) ทองเป็นตัวสร้างผล 2025 ของ M019 — ถ้ากองอื่นชนะ SR12′ ในบางไตรมาส อาจเสียช่วงทองขึ้นแรง (CAGR อาจ **ลด**) · (2) กอง O ไทยมีน้อยและหลายกองข้อมูลมีรู → อาจเลือกได้แค่ทองเกือบทุกไตรมาส (ผลเท่าเดิม) · (3) F ต่างประเทศ hedged/unhedged ทำให้เดาค่าเงินโดยไม่ตั้งใจ

## ไอเดีย 6 — ENS2: รวม 2 กติกาคัดกอง (M019-LC3 + M022-LC5P10) ครึ่งต่อครึ่ง
**อัลกอริทึม**: ทุน 1/2 เดิน M019 ทุกบิต · 1/2 เดิน M022-LC5P10-GCGOLD ทุกบิต · จำลองแยกแล้วรวมค่าพอร์ต (วิธีเดียวกับ TR3) · offset test: ทั้งคู่ใช้ offset เดียวกัน
- ความยาก: ง่าย (plan ทั้งสองมีอยู่ — แค่รวมค่าพอร์ต)
- **ช่วยเป้าข้อไหน**: ข้อ 2 — ลด "selection luck" (R003: ส่วนต่างตาม N คือ noise ของการเลือกกอง · M009 กองเดียวขยับ Sharpe ~0.2) · ทั้งสองตัวเฉลี่ย offset ใกล้เกณฑ์ (1.00 / 0.94) และเลือกกองต่างกันบางส่วน (เทียบ `M019_quarters` กับ `M022_quarters`)
- **หลักฐาน (ปานกลาง–อ่อน)**: หลัก parameter diversification (R003 ไอเดีย N-ensemble · Newfound — ยังไม่ยืนยันแหล่งเฉพาะ) · ไม่มีงานเฉพาะกองทุน
- **ความเสี่ยง**: Sharpe รวมไม่น่าเกินตัวดีกว่า (M019) มาก → ข้อ 1 ไม่ผ่านแน่ถ้าใช้เดี่ยว · มีค่าเมื่อเป็นชั้นล่างของ TR3 (TR3×ENS2 = 6 ก้อน) เท่านั้น

## 8. คำแนะนำถึง modeler (ลำดับรัน)
1. **TR3 บน M019** + diagnostic แยกช่องว่าง offset รายไตรมาส (0 trial) — วัดว่าเฉลี่ยข้ามเวลาแล้ว M019 "จริงๆ" อยู่ตรงไหน (ตัวเลขนี้ควรเป็นฐานของทุกไอเดียต่อไป ไม่ใช่ 1.10 ของ offset 0)
2. **FEE0** และ **SM3** บน M019 (แยกกัน) — FEE0 คือทางเดียวที่ดัน Sharpe ขึ้นโดยไม่พึ่งโชค
3. **MH**, **DEFX** บน M019 (แยกกัน)
4. รอบ 2: TR3 × (ไอเดียที่ไม่ทำให้เฉลี่ย offset ลด) — เช่น TR3+FEE0(+MH/DEFX) · ENS2 ใช้เฉพาะเป็นชั้นล่างของ TR3

## 9. ต้องให้ผู้ใช้ตัดสินใจ
1. ถ้า TR3 ผ่านข้อ 2 แน่นอนแต่ข้อ 1 ลดจาก 1.10 (เพราะเอาโชค offset 0 ออก) ผู้ใช้ยอมรับไหมว่า "ข้อ 1 ของ TR3" คือตัวเลขที่ซื่อตรงกว่า
2. พอร์ตจริงแบบ TR3 จะถือได้ถึง ~9 กองหุ้น + ขากัน และทำรายการทุกเดือน (ทีละ 1/3) — รับได้ในทางปฏิบัติไหม (ขั้นต่ำซื้อของกอง/ภาระงาน)
