### M029-BAND5 — no-trade band 5 pt สำหรับกองที่ถือต่อ (path-neutral · ปานกลาง)
ฟังก์ชันใหม่ `band_plan(plan, nav_all, band)` ประมวลผลต่อ plan ของแต่ละ offset หลัง `gc_gold_plan` (เรียงตามเวลา · state = รายการก่อนหน้าที่ผ่าน band แล้ว):
```
entry 0: w_new = w_T                                        # ไม่มีของถือ
entry j: prev = w_new(j−1) ; p0(i) = NAV ราคาซื้อ ณ e(j−1) (simulate._exec_nav) ; p1(i) = NAV asof t_j (fs._asof · NAV ≤ t_j)
  w_d(i) ∝ prev(i) · p1(i)/p0(i)  (Σ = 1 · ราคาไม่มี → ตัด i ออกจาก F)
  F = {i ∈ w_T ∩ w_d : |w_T(i) − w_d(i)| ≤ band} ; T = w_T ∖ F
  w_new(i) = w_d(i) (i ∈ F) ; w_new(i) = w_T(i)·(1 − Σ_F w_d)/Σ_T w_T (i ∈ T) ; T ว่าง → w_new = w_d|F ปรับ Σ = 1
```
- ใช้กับทุกกองใน plan (หุ้น + ทอง + ตลาดเงิน — ทอง/ตลาดเงิน FF ≈ 0 จึงไม่มีผลต้นทุน) · พารามิเตอร์ค่าเดียว band = 0.05 (Vanguard 5 pp · ไม่จูน)
- regression: band = 0 → plan = M024 ทุกบิต · **assert**: ชุดกองหุ้น (w > 0, ไม่อยู่ใน fset) ต่อไตรมาส = M024 ทุก offset
- รายงานเพิ่ม: จำนวน fund-quarter ที่อยู่ในแถบ · ต้นทุนที่ลด (bp/ปี เทียบ D1 ถัง ข2) · max |x จริง − x_t| · turnover ที่เหลือจาก drift t→e

### M030-SIW — ต้นทุนเข้าที่นับช่องสับเปลี่ยน (แตะเส้นทาง · ง่าย ~15 บรรทัด)

```

```
