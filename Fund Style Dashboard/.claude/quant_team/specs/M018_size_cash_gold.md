## 4. ส่วนที่เปลี่ยน (ล็อก)

3. **EQ100**: x_t = 1 ทุกไตรมาส · ไม่มีกองตลาดเงิน/เงินสด
4. **กองทอง (GCGOLD)** ณ t — กติกาขนานกับกอง F ของ M015-FAUM:
   - ชนิดกอง: `Fund Policy` = O · `Fund Name EN` มีคำว่า "GOLD" · Tax Type ว่าง · `buy period flag` = N · `Project Retail Type` = R · ชื่อไม่มี "Not for Retail"/"TEST"

   - ข้อมูล ณ t: NAV ล่าสุด ≤ 90 วัน · ≥ 252 NAVDate ตั้งแต่ 2021 · สด ≤ 10 วัน · ตัด class ภาษี · ตัด -D ถ้ามี class สะสม · สัญญาณคำนวณได้
   - คุณภาพ: AUM_fam ≥ 100 ล้าน · อายุ ≥ 730 วัน
   - เลือก: **family ที่ AUM_fam ใหญ่สุด** → class ตัวแทน = SR12′ สูงสุดใน family (กติกาเดิม · **ไม่บังคับ H/UH** — ผู้ใช้เลือก 2026-10-12)

## 6. รายงาน (ทุกแบบ · ห้ามเลือกตัวที่ดีที่สุดเป็นผลงาน)
- Sharpe / CAGR / vol / Max DD / ผลตอบแทนรายปี 2022 (เม.ย.–ธ.ค.) 2023 2024 2025 · กรณีค่าธรรมเนียม full / nofront / flat 0.5% / 0%
- CI95% block bootstrap (3 เดือน, 2000, seed 0) · **DSR@44** · offset 0/1/2 (ช่วงร่วม ก.ค. 2022 – ธ.ค. 2025)
- ตาราง 3×3 (N × ขา) ของ Sharpe และ CAGR · paired ΔSharpe: GCMMF vs EQ100 และ GCGOLD vs GCMMF ต่อ N
- **ต้นทุนแยกส่วน (bp/ปี)**: ขาหุ้น (สลับกอง + เพิ่มหุ้นกลับ) · ขากัน (เข้า/ออกกองตลาดเงินหรือทอง) · สัดส่วนที่ไปช่องทางสับเปลี่ยน
- ขากัน: กองที่ถูกเลือกต่อไตรมาส (FundCode, class H/UH, บลจ., AUM_fam, ค่าธรรมเนียม) · ผลตอบแทนขากันรายไตรมาสเทียบ rf · จำนวนไตรมาสที่ขาทองตกไปกองตลาดเงิน
- ความกระจุก: น้ำหนักกองเดียวสูงสุด · จำนวนไตรมาส fallback B0 · turnover/ปี
