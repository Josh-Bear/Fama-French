## 2. การคัดกองหุ้น ณ สิ้นไตรมาส t (ข้อมูล ≤ t · ล็อก)
ขั้นก่อนหน้าเหมือน M018 ทุกบิต: I_t + เกณฑ์คุณภาพ S → class ตัวแทน (SR12′ สูงสุด / class ที่ถือ) → อันดับ family ตาม SR12′
```
P   = family ที่อันดับ ≤ 9                                   # กลุ่มผู้สมัคร (ผู้ใช้กำหนด)
S   = กองที่ถืออยู่ (ไตรมาสก่อน ไม่ fallback) ที่ยังอยู่ใน P และ class ตัวแทนเป็น class เดิม      # ถือต่อ (ผู้ใช้กำหนด: ติด top 9)
if S ว่าง: S = {อันดับ 1}
while |S| < 3 และ P \ S ไม่ว่าง:
    สำหรับ c ใน P \ S: score(c) = max_{s ∈ S} ρ_adj(c, s)      # ค่าสูงกว่า "ต่ำที่สุด" (ผู้ใช้กำหนด)
    เลือก c ที่ score ต่ำสุด · เสมอ → อันดับ SR12′ ดีกว่า
ρ_adj = run_m010.rho_adj_pair (weekly 52 สัปดาห์ ≤ t · lead-lag lag 1 เต็มน้ำหนัก · สัปดาห์ร่วม < 30 → NaN → นับเป็น 1.0)
```
- กองถือต่อไม่ถูกตัดเพราะ correlation · ถ้ามีกองถือต่อ 3 กอง → ไม่มีการเติม
- ได้ < 3 กอง (P มีไม่ถึง 3 family): ใช้เท่าที่ได้ · ERC เพดาน 40% → น้ำหนักส่วนหุ้นที่เหลือ (เช่น 2 กอง = 80%) **ย้ายไปขากัน (กองทอง)** · รายงานจำนวนไตรมาส
- ได้ < 2 กอง → fallback B0 (เกณฑ์ max(2, ⌈3/2⌉) = 2 เหมือน M018-N3)
