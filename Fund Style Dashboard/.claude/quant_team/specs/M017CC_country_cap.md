# M017-CC — M017-IDX + เพดานต่อประเทศ (country cap)

สถานะ: **ลงทะเบียนล่วงหน้า 2026-10-07** — เขียนก่อนรัน M017-CC และก่อนเห็นผลใดๆ ของ M017-IDX (ตอนเขียน M017-IDX ยังรันไม่เสร็จ — มีแค่ smoke test การเลือกกอง offset 0 ไม่มี return)
· ผู้ออกแบบ: quant-modeler (กติกาจากผู้ใช้ผ่านหัวหน้าทีม) · model_id: **M017-CC** · **trial #35 → n_trials_cumulative = 35**
base: **M017-IDX** (`specs/M017_index_first.md`) ทุกบิตยกเว้นที่ระบุด้านล่าง · ห้าม tune / ไม่มีตัวแปรอื่น

## 1. สมมติฐาน
- กองไทยส่วนใหญ่มี country_primary = USA/EUROPE → แม้ M017 บังคับ 1 ดัชนี → 1 กอง กองที่ได้มาจาก sector index อาจซ้ำประเทศเดิม
  → เพดานประเทศลด concentration risk (ไม่ใช่ไอเดีย alpha) · คาด vol/DD ลดเล็กน้อย, CAGR ±, อาจมีเงินสดเพิ่มเมื่อมีประเทศ < 3

## 2. กติกาที่ล็อก
1. **ประเทศของกอง** = `country_primary` ณ t จาก `exposure.py` (11 ดัชนี VIF-clean, expanding ≤ t, cache เดียวกับ M017) — ไม่สนว่าถูกเลือกผ่านดัชนีประเทศหรือ sector และไม่สน country R²
   · กองที่ไม่มี country_primary (ไม่มีผล fit) → ถือเป็นประเทศเฉพาะของตัวเอง ("NA:<FundCode>")
2. **เพดาน = 40% ของส่วนหุ้น** (ไม่รวมเงินสด Trend 25) ต่อผลรวมกองที่มี country_primary เดียวกัน
3. **การเลือก**: ระหว่างเดินเติม (ขั้น 2.4 ของ M017) ถ้ากองที่เลือกแล้ว (ถือต่อ + ใหม่) มีประเทศเดียวกับผู้สมัคร **≥ 2 กอง** → ปัดผู้สมัคร (ไปผู้สมัครถัดไป/ดัชนีถัดไปตามปกติ; นับ rej_country)
   · ตรวจหลังกฎ a/b และก่อนกฎ c (correlation) · กองถือต่อ **ไม่ถูกบังคับขาย** ด้วยกฎนี้
4. **น้ำหนัก**: ERC (LW) → วนเพดานกอง 25% และเพดานประเทศ 40% ร่วมกัน: ส่วนเกินกระจายตามสัดส่วนน้ำหนักให้กองที่ต่ำกว่าเพดานกองและอยู่ในประเทศที่ต่ำกว่าเพดานประเทศ
   (ประเทศที่ติดเพดานจึงไม่รับเพิ่ม) จนไม่มีส่วนเกิน (≤ 1e-12, สูงสุด 500 รอบ) · ถ้าไม่มีผู้รับ (เช่น < 3 ประเทศ) → ส่วนที่กระจายไม่ได้ไปเป็น **เงินสด** (rf จริง, เพิ่มจากเงินสด Trend 25:
   เงินสดรวม = c_trend + (1 − c_trend) × ส่วนที่เหลือ) · บันทึกจำนวนไตรมาสและขนาด
5. fallback B0 (< 4 กอง) ใช้ `b0_w` เดิม **ไม่ใช้เพดานประเทศ** (เหมือน M017) · อื่นๆ ทั้งหมด = M017-IDX
6. **เกณฑ์ตัดสินเดียวกัน**: ผ่าน = CAGR > 9.09% และ maxDD ≥ −20% (fee full, offset 0, 45 เดือน) · Sharpe รายงานคู่
   · รายงาน: fee full/nofront/flat/0%, offset 0/1/2, paired Δ vs Trend 25 / M012-QF-S / M017-IDX, ต่อไตรมาส (picks, ประเทศ, น้ำหนักประเทศสูงสุด, rej_country, เงินสดจาก infeasible), DSR@35
