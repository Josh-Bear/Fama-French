# M004 — M003-ERC + overlay เงินสด (vol targeting / trend filter) · เงินสด ≤ 25%

- ผู้เขียน: quant-modeler · 2026-09-30 · สถานะ: **pre-registered** · องค์ประกอบกลาง `M002-M005_plan.md`
- trials: **2** (M004-VT, M004-TF) · n_trials_cumulative 8–9 · parent = **M003-ERC** (กำหนดล่วงหน้า ไม่เลือกตามผล M003)

## 1. สมมติฐาน + หลักฐาน
1. **Vol targeting**: ความผันผวนของหุ้น persistent แต่ผลตอบแทนคาดหวังไม่เพิ่มตาม → ลดสัดส่วนหุ้นเมื่อ vol สูงช่วยเพิ่ม Sharpe
   (Moreira & Muir 2017; Harvey, Hoyle, Korgaonkar, Rattray, Sargaison, Van Hemert 2018 — ผลชัดสุดในหุ้น ผ่านการลด left tail)
2. **Trend filter**: ตลาดที่ต่ำกว่าเส้นค่าเฉลี่ย 10 เดือน/200 วันมี return คาดหวังต่ำและ vol สูง (Faber 2007; Moskowitz–Ooi–Pedersen 2012 TSMOM)
   → ถือเงินสด 25% ในช่วงตลาดขาลง
3. ข้อจำกัดสำคัญ: เงินสด ≤ 25% → ลด beta ได้สูงสุด 25% · ตัดสินใจรายไตรมาสเท่านั้น → ปฏิกิริยาช้า (overlay จะช่วยเฉพาะขาลงที่ยาวกว่า 1 ไตรมาส เช่น 2022)

## 2. อัลกอริทึม ณ วัน t
1. S และน้ำหนักส่วนหุ้น w (Σ=1) = M003-ERC ทุกประการ (assert ว่าตรงกัน)
2. **M004-VT**: c = c_VT ตาม C9 (σ̂ จากพอร์ต w ย้อนหลัง 13 สัปดาห์ ≤ t · σ* = 10% · clip [0, 0.25])
3. **M004-TF**: c = c_TF ตาม C10 (MSCI_ACWI THB < SMA200 ณ t → 0.25 ไม่งั้น 0)
4. น้ำหนักสุดท้าย: กอง i = (1 − c)·wᵢ · `__CASH__` = c (C7 — ขาเงินสดไม่มีต้นทุน · ขากองที่ลดลงเสียต้นทุนตามปกติ)
5. เพดานต่อกอง 25% คิดบนส่วนหุ้น (wᵢ) → น้ำหนักจริง ≤ 25%

## 4. สิ่งที่คาด
- VT: เงินสดเฉลี่ย ~3–8% (ส่วนใหญ่ 0) สูงในไตรมาสหลัง vol พุ่ง (กลาง–ปลาย 2022) · Sharpe Δ +0.0–0.1 · maxDD ดีขึ้น 1–3 pt
- TF: สลับเข้า/ออกเงินสดไม่กี่ครั้ง (คาด 2–5 ครั้งใน 15 ไตรมาส) · ต้นทุนต่อการสลับเข้า/ออกเงินสด 1 ครั้ง = 25% × 0.5% = 0.125% (ขากองข้างเดียว)
  · Δ Sharpe −0.05…+0.1 (เสี่ยง whipsaw ในปี 2023 ที่ตลาดกลับตัวเร็ว)
- ทั้งคู่ทำให้ CAGR ลดในปีขาขึ้น (2023–2025 cash drag ~0.5–2%/ปีในช่วงที่ถือ)

## 5. ความเสี่ยง
- **จำนวนเหตุการณ์น้อยมาก**: ขาลงจริงในช่วง primary มีแค่ปี 2022 → ผล overlay พึ่ง 1 ช่วง (ห้ามตีความว่าพิสูจน์แล้ว)
- ค่า 10%/200 วัน เป็นค่ามาตรฐานวรรณกรรม ไม่ได้ tune · ถ้าผู้ใช้ขอ sensitivity σ* ต้องนับเพิ่ม 2 trials
- ตัดสินใจรายไตรมาส: TF ณ 2022-03-31 ขึ้นกับว่า ACWI THB อยู่ใต้ SMA หรือไม่ (ไม่ได้ตรวจล่วงหน้าเพื่อกัน snooping)
