## 1. สมมติฐาน + คาดการณ์ ex-ante (ซื่อตรง)
1. **นี่เป็นตัวกรองความเสี่ยงเชิงปฏิบัติ ไม่ใช่ไอเดีย alpha**: กอง feeder ไทยขนาดเล็กเสี่ยงถูกเลิกกอง/ควบรวม (บังคับขาย + ต้นทุนเข้าใหม่) ·
   สภาพคล่อง/ค่าใช้จ่ายต่อหน่วยแย่กว่า · เสนอลูกค้าไม่ได้จริงถ้ากองเล็กมาก · กองที่ข้อมูลสั้นมี SR12 จาก track record สั้น + เสี่ยง incubation/backfill bias
   (Evans 2010 JF "Mutual Fund Incubation" — ไม่ได้เปิดอ่านเอง)
2. **หลักฐานด้าน return ไม่สนับสนุนว่ากองใหญ่ดีกว่า**: งานกองหุ้น US พบ diseconomies of scale (Chen, Hong, Huang & Kubik 2004 AER — ไม่ได้เปิดอ่านเอง)
   และ R001 จัด AUM เป็น "ไม่แนะนำ" ในฐานะ**สัญญาณ** (AUM มีรู, ทิศทาง Berk–Green ไม่ชัด) — M012 ใช้ AUM เป็น**เกณฑ์ขั้นต่ำแบบ binary** ไม่ใช่สัญญาณจัดอันดับ จึงไม่ขัด R001
   · สำหรับ feeder ขนาดที่มีผลต่อ return คือกองแม่ ไม่ใช่กองไทย → **ไม่คาดว่า Sharpe เพิ่ม**
3. **เกณฑ์ผูกมัดจริง (binding)**: ในเส้นทางของ M011-RFH มีกองที่ถือแต่ AUM_fam < 100 ล้าน **1–4 กองใน 11/15 ไตรมาส** (§5) → ชุดกองจะต่าง "ตรงๆ" หลายไตรมาส
   → **Δ จะเป็น path luck เป็นส่วนใหญ่** (M009: เปลี่ยน ~1 กอง → ต่าง 14/15 ไตรมาส Δ −0.20 · M010/M011 ทำนองเดียวกัน) · คาด Δ ช่วง ±0.2, ค่ากลางเป็นลบเล็กน้อย
   (opportunity set เล็กลง ~20–25%) · turnover อาจเพิ่มจากการขายบังคับเมื่อ AUM หลุด
4. ไม่คาดว่าแก้จุดอ่อนปี 2022 · ไม่มุ่งเป้า 0.95

## 2. อัลกอริทึม ณ t (point-in-time)
```
ข้อมูล: nav = cache/nav_clean.parquet ทั้งไฟล์ (ไม่กรอง 2021) · ใช้เฉพาะแถว NAVDate ≤ t
fam(fc) = fs.family_of(fc, groups)[0]     # map เดียวกับ I_t (รวม -F/-U)

(Q1) AUM
  aum_c(fc,t) = AUM ของแถวล่าสุดที่ NAVDate ≤ t และ AUM > 0 (ไม่ NaN) และ NAVDate ≥ t − 90 วัน ; ไม่มี → 0
  AUM_fam(F,t) = Σ aum_c ของ "ทุก class" ใน family F ที่มีในไฟล์ (รวม class ภาษี/ปันผล/class ที่ไม่สด)
  pass_Q1 = AUM_fam ≥ 100_000_000     # บาท

(Q2) ประวัติ — แบบ A (ตามคำสั่งผู้ใช้)
  First_fam(F,t) = min NAVDate ของทุก class ใน F (NAVDate ≤ t)
(Q2) ประวัติ — แบบ B (ทางเลือก, แนะนำ)
  first_c = min( Registration_date ของ fc ใน base_data/FundProfile.csv (join 'Fund Code' == FundCode ตรงตัว, รูปแบบ YYYYMMDD),
                 NAVDate แรกของ fc )            # ไม่มี Registration_date → ใช้ NAVDate แรก ; Registration_date > t → ไม่นับค่านั้น
  First_fam(F,t) = min first_c ของทุก class ใน F
  pass_Q2 = First_fam ≤ t − 730 วัน

I_t' = { แถวใน I_t (fs.investable_set เดิม) ที่ family ผ่าน Q1 และ Q2 }
ต่อจากนั้นเหมือน M011 ทุกบิต: family_representatives(I_t', held) → rank_families → hysteresis_select → ERC → cap → trend cash
```
- **ระดับ family ไม่ใช่ class**: (Q1) AUM ในไฟล์เป็น **ต่อ class** (ตรวจ 66 คู่ family-วันเดียวกัน ณ สิ้น 2025: AUM เท่ากันข้าม class 0 คู่ เช่น ES-GQG 22,246 ล้าน
  vs ES-GQG-UH 207 ล้าน) และความเสี่ยงเลิกกองเป็นของกองทั้งก้อน → รวมทุก class · (Q2) class ใหม่ของกองเก่าไม่ใช่กองใหม่ → ใช้ min ข้าม class
- **หน่วยเป็นบาท**: median AUM ทั้งไฟล์ 326.7 ล้าน, p90 2,838 ล้าน · AUM/NAV (จำนวนหน่วย) median ~31 ล้านหน่วย → สมเหตุสมผลกับหน่วยบาท (ไม่ใช่ล้านบาท)
- **กติกา AUM ว่าง/0**: AUM = 0 มี 1.5% ของแถว (NaN 0%) — ถือเป็น "ไม่รายงาน" ไม่ใช่ขนาดจริง 0 (กองที่ยังมี NAV ไม่ควรมีทรัพย์สิน 0) → ใช้ค่าบวกล่าสุด
  ภายใน **90 วัน** (= `config.NAV_STALE_MAX_DAYS` ค่าคงที่เดิมของระบบ ไม่ได้ tune) · เกิน 90 วัน = ไม่รู้ขนาด → **ไม่ผ่าน** (อนุรักษ์นิยม)
  · ex-ante: family ที่ไม่มี AUM บวกใน 90 วันมี 0–1 family ต่อไตรมาส → กติกานี้แทบไม่มีผล
- 100 ล้าน และ 730 วัน = ค่าคงที่ที่ผู้ใช้กำหนด ห้ามลองค่าอื่นภายใต้ชื่อนี้
