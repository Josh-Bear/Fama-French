## 1. สมมติฐาน + คาดการณ์ ex-ante (ซื่อตรง)
1. **ความถูกต้องเชิงนิยาม**: SR12 ควรเป็น "excess return ต่อความเสี่ยง" ของโอกาสจริงที่นักลงทุนไทยมี ณ ช่วงนั้น (Sharpe 1994 ใช้ rf ร่วมสมัย) · 2% คงที่สูงเกินจริง
   ในปี 2021–22 (ดอกเบี้ย 0.5%) และต่ำไปในปี 2024 (2.5%) · นี่เป็นการแก้ความสอดคล้อง ไม่ใช่ไอเดีย alpha ใหม่
2. **กลไกเดียวที่อันดับเปลี่ยนได้**: h_t เท่ากันทุกกองใน t เดียวกัน → SR12' − SR12 = (0.018333 − h_t) ÷ vol52_i → อันดับสลับได้เฉพาะคู่ที่ vol ต่างกัน
   และ SR12 ห่างกันไม่เกิน |Δh|·|1/v_i − 1/v_j| · Δh < 0 (hurdle ลด) = เอียงไปกอง vol ต่ำ · Δh > 0 = เอียงไปกอง vol สูง
3. **ขนาด Δh (คำนวณจากไฟล์ดอกเบี้ยเอง, ใช้สิ้นเดือนปฏิทินประมาณ)**: 2022-03 … 2022-09 ≈ **−1.37 pt** · 2022-12 −1.25 · 2023-03 −1.05 · 2023-06 −0.75 ·
   2023-09 −0.38 · 2023-12 −0.04 · 2024 Q1–Q4 +0.23 … **+0.50** · 2025 Q1–Q3 +0.39 … +0.04 · 2025-12 −0.17 (pt ของ return 11 เดือน)
   → ผลต่อ SR12: vol 8% ได้ +0.17, vol 25% ได้ +0.055 ในปี 2022 (ต่างกัน ~0.12) · ปี 2024 ทิศกลับ ≤ ~0.06 · ช่วงอื่น < 0.05
4. **คาดว่าผลเล็กมาก**: ส่วนใหญ่ของ 15 ไตรมาสน่าจะได้ชุดกองเดิม · ไตรมาสที่มีโอกาสสลับตรงๆ คือ 2022 Q1–Q4 (+ 2023 Q1) ที่ขอบอันดับ 8/16
   · ถ้าสลับ 1 กองในปี 2022 hysteresis จะพา path ต่างไปหลายไตรมาส (M009: เปลี่ยน ~1 กอง/ไตรมาสแรก → ต่าง 14/15 ไตรมาส, Δ −0.20) → **Δ จะเป็น path luck
   เกือบทั้งหมด** ไม่ใช่มูลค่าของ hurdle · ทิศที่พอคาดได้: เอียงกอง vol ต่ำในปี 2022 อาจช่วยขาลงเล็กน้อย (low-vol anomaly) แต่ไม่คาดว่าถึง 0.95
   · คาด Δ ≈ 0 ถ้าไม่มีการสลับ, ช่วง ±0.2 ถ้า path เปลี่ยน

## 2. hurdle h_t ณ t (point-in-time · ล็อก)
```
อัตรา ณ วันปฏิทิน d:  r(d) = rate_pct/100 ของแถวที่ announce_date มากสุดโดย announce_date < d     # มีผลวันถัดจากวันประกาศ
                        (อ่านด้วย comment="#" · เรียง announce_date · forward-fill ระหว่างมติ — ปี 2017 ไม่มีแถว = 1.5% ต่อเนื่อง)
ctx  = QuarterContext / SignalContext เดิม ณ t
a    = ctx.months[0]    # สิ้นเดือน M-12 (วันทำการสุดท้ายของปฏิทินดัชนีในเดือนนั้น — จุดเดียวกับ p_m12 ของ R12-1)
b    = ctx.months[-2]   # สิ้นเดือน M-1  (จุดเดียวกับ p_m1)
h_t  = Π_{d = a+1 วัน … b (ทุกวันปฏิทิน)} (1 + r(d)/365) − 1                                        # ACT/365 ทบรายวัน
SR12'_i = (R12_1_i − h_t) / vol52_i                      # R12_1, vol52 เดิมทุกตัว · h_t ค่าเดียวทุกกองใน t
```
- point-in-time: ทุก d ≤ b < t และใช้แถวที่ announce_date < d ≤ t เท่านั้น → ไม่มี look-ahead · ห้ามใช้ค่าเฉลี่ยรายปี
- ถ้า len(ctx.months) < 13 → SR12 เป็น NaN อยู่แล้วตามโค้ดเดิม (ไม่ต้องคิด h_t)
- การ implement ที่แนะนำ (`backtest/run_m011.py`, ห้ามแก้โค้ดแอป): หลัง `compute_quarter_signals` แทนคอลัมน์ `SR12` ด้วย SR12' แล้วส่งต่อทุกขั้นที่ใช้ SR12
  (ตรวจว่ามีขั้นไหนอ่าน SR12 นอกจาก rank — เช่นการเลือก class ตัวแทน — ต้องใช้ SR12' เหมือนกันทั้งหมด)
- ค่าตรวจ (สิ้นเดือนปฏิทิน · ของจริงใช้ปฏิทินดัชนี ต่างได้ ≤ 2e-4): 2022-03-31 ≈ 0.00459 · 2024-09-30 ≈ 0.02328 · 2025-12-31 ≈ 0.01662

## 3. วิธีวัดด้วย rf จริง (ใช้กับทั้ง M011 และ Trend 25 (rf จริง) เหมือนกันทุกบิต)
**ถ้า `backtest/remeasure_real_rf.py` / `results/REAL_RF_remeasure.md` มีแล้วตอนรัน → ใช้ฟังก์ชัน/นิยามของไฟล์นั้นทั้งหมด** และรายงานว่าต่างจากข้างล่างตรงไหน
· ถ้ายังไม่มี ใช้นิยามนี้:
```
เงินสด (แทน _grow_cash):  cash(d1) = cash(d0) × Π_{d = d0+1 … d1} (1 + r(d)/365)      # ครอบคลุมเงินสดเป้าหมาย 25% (trend) และเงินที่ซื้อไม่ได้
rf ต่อช่วงผลตอบแทน:      ให้ p_0 < p_1 < … = index ของ value series ที่ simulate คืน (จุดเริ่ม e + สิ้นเดือน)
                          rf_k = Π_{d = p_{k−1}+1 … p_k} (1 + r(d)/365) − 1
excess:                   x_k = r_k − rf_k     (r_k = value[p_k]/value[p_{k−1}] − 1)
Sharpe:                   mean(x)·12 / (sd(x, ddof=1)·√12)
```
- implement ง่ายสุด: ส่ง **x_k** เข้า `simulate.sharpe / block_bootstrap_ci / paired_bootstrap_diff_ci / deflated_sharpe` ด้วย `rf_annual = 0`
  (paired bootstrap จึง resample คู่ excess ของสองแขนด้วยบล็อกเดียวกันอยู่แล้ว)
- รายงานคู่ (ไม่ตัดสิน): ตัวหาร sd(r) แทน sd(x) · Sharpe ของ M011 ที่วัดด้วย rf คงที่ 2% แบบเดิม

## 5. สิ่งที่ขอให้ backtest-validator รัน + เกณฑ์ (ล็อกล่วงหน้า)
**regression (ไม่ผ่าน = หยุด ไม่นับ trial)**
1. ตั้ง h_t := 0.02 × 11/12 (สูตรเดิมตรงตัว ไม่ใช่ทบด้วย 2%) → น้ำหนักเท่า `M004-TF-FX_weights.csv` ทุกแถว (max|Δw| < 1e-9) และวัดแบบเดิม (rf คงที่) ได้ Sharpe full **0.706119**
2. โค้ดวัดใหม่ในโหมด rf คงที่ (`_grow_cash` เดิม + rf 2%/12) ให้ 0.706119 เช่นกัน · โหมด rf จริงไม่ crash ที่ขอบปี/ขอบมติ
3. ตรวจ h_t ทั้ง 16 ไตรมาสเทียบค่าตรวจ §2 · spot check `r(d)`: 2022-08-10 = 0.50%, 2022-08-11 = 0.75%, 2024-10-17 = 2.25%

**ตัวชี้วัดหลัก**: Δ = Sharpe_full(M011, rf จริง) − Sharpe_full(Trend 25, rf จริง) paired 45 เดือน · CI95% `paired_bootstrap_diff_ci` (block 3, 2000, seed 0)

| ผล | เงื่อนไข (เกณฑ์ผู้ใช้แบบ M010) |
|---|---|
| **ผ่าน** | Δ ≥ 0 (CI ล่าง > 0 → ติดป้าย "ดีกว่าอย่างมีนัย") |
| **ไม่ผ่าน** | Δ < 0 ใดๆ → คง Trend 25 · ไม่รันซ้ำด้วยค่าอื่น |
| **ไม่มีผล** | ชุดกอง + น้ำหนักเท่า Trend 25 ทุกไตรมาส → M011 ≡ baseline (ยังนับ 1 trial) |

**รายงานคู่ (ไม่ใช้ตัดสิน)**
- h_t รายไตรมาส และ Δh = h_t − 0.018333 · Spearman ของ SR12 vs SR12' ใน I_t ต่อไตรมาส · จำนวนกองที่อันดับข้ามขอบ 8 และ 16
- **จำนวนไตรมาสที่ชุดกองต่างจาก Trend 25** แยก "ต่างตรงๆ" (รัน `select_at` ด้วย SR12' แต่สถานะถือ = ของ Trend 25 ณ t แล้วยังต่าง) vs "สืบทอดผ่าน hysteresis"
- Δ path luck: Δ ของเดือนในไตรมาสที่ชุดกองเหมือนกัน vs ต่างกัน · ถ้า Δ มาจากไตรมาส/กองเดียวให้ระบุ (แบบ M009/M010) · drop-best-quarter
- Sharpe/CAGR/vol/maxDD ที่ 0%, 0.5%/ข้าง, full, nofront · turnover/ปี · cost bp/ปี · Sharpe ย่อย 2022 และ 2023-07..2025-12 · DSR@23 · CI Sharpe เดี่ยว
- ผลของวิธีวัดอย่างเดียว: Sharpe Trend 25 (rf จริง) − 0.706119 (ไม่ใช่ trial) · พอร์ต 2025-12-31 (หน้า 9) ต่างจากเดิมไหม
