## 1. เหตุผล (ex-ante)
- rebalance ช้าลง = turnover/ต้นทุนต่ำลง (M004-TF turnover ~44%/ไตรมาส × 0.5%/ข้าง) · momentum กองทุน 12-1 มี half-life หลายเดือน
  (Jegadeesh–Titman 1993: กำไรถึง ~12 เดือน) → คาดว่าเสียสัญญาณไม่มาก · ความเสี่ยง: สัญญาณเก่า/กองที่เลือกหมดแรง
- เงินสดไล่ระดับแทน on/off ลด whipsaw · เพดาน 30% = ผู้ใช้ต้องการให้ยังเป็นพอร์ตหุ้นเป็นหลัก

## 2. อัลกอริทึม
**ส่วนหุ้น (เหมือน M004-TF ทุกข้อ ยกเว้นความถี่):** family map ใหม่ (§F1 ด้านล่าง) · SR12 · N=8 · hysteresis K=16 · ERC (LW, 52 สัปดาห์) · cap 25% ต่อกอง
— คำนวณเฉพาะวัน rebalance R (ด้านล่าง) · ระหว่างรอบไม่คัดกอง/ไม่คำนวณ ERC ใหม่

**วัน rebalance (offset):** ทุก offset เริ่มคัดครั้งแรกที่ **2022-03-31** (ทุก offset ช่วงวัดผลเดียวกัน) แล้วรอบถัดไปเป็นสิ้นไตรมาสที่ตรง offset
- 6M: offset A = มี.ค./ก.ย. · offset B = มิ.ย./ธ.ค. (B: 2022-03, 2022-06, 2022-12, 2023-06, …)
- 12M: offset มี.ค. / มิ.ย. / ก.ย. / ธ.ค. (เช่น offset มิ.ย.: 2022-03, 2022-06, 2023-06, 2024-06, 2025-06)

**ส่วนเงินสด (ทุกสิ้นเดือน m, ทุก trial):** สัญญาณ s_3, s_6, s_12 ตาม M006 §3.2 (ACWI THB excess over rf)
- `k = จำนวนสัญญาณที่เป็น 0 (ติดลบ)` ∈ {0,1,2,3} → **เงินสด c_m = 0.10 × k** · หุ้น x_m = 1 − c_m ∈ {1.0, 0.9, 0.8, 0.7}
- ถ้า c_m เปลี่ยนจากเดือนก่อน → entry `mode="scale"` ตาม M006 §4 (ย่อ/ขยายกองที่ถือตามสัดส่วน drift · ต้นทุนเฉพาะขากอง)
- วัน rebalance ใช้ entry ปกติตัวเดียว: กอง i = x_m · w_i · เงินสด = c_m (ห้ามซ้อน scale)
- execution / look-ahead ตาม M006 §3.4 (ข้อมูล ≤ m · ซื้อขายวันทำการที่ 2 หลัง m)

**headline ต่อ trial = พอร์ต tranche:** แบ่งเงินเท่ากันเป็น 2 ก้อน (6M) หรือ 4 ก้อน (12M) ก้อนละ offset · ไม่ย้ายเงินข้ามก้อน
→ equity ของ trial = **ค่าเฉลี่ยของ equity curve ทุก offset (ทุกเส้นเริ่ม 100)** แล้วคำนวณ return รายเดือน/metrics จากเส้นนั้น
· รายงาน Sharpe ของแต่ละ offset (min–max) คู่กันด้วย · ห้ามเลือก offset ที่ดีที่สุด
