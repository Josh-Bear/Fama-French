  (ยังใช้ SR12 ดิบ + ถือ class เดิม — ดู §3 ข้อ 4)**, นิยาม SR12/vol52, N=8, K=16, TF_MIN_FUNDS=4 + fallback B0, ERC Ledoit-Wolf 52 สัปดาห์
  (+ inverse-vol เมื่อสัปดาห์ร่วม < 30), cap 25%/กอง, ACWI < SMA200 → เงินสด 25% (rf 2%), rebalance สิ้นไตรมาส, ซื้อขาย NAV วันทำการที่ 2,
  ไม่มี NAV ใน 10 วันทำการ → เงินสด, rf Sharpe 2%, ช่วงประเมิน 45 เดือน (เม.ย. 2022–ธ.ค. 2025, วิธีวัดใหม่นับเดือนแรก), ไม่มี holdout
- การคิดต้นทุนจริงในการจำลอง **ใช้ `FeeModel` เดิมทุกกรณี** (full / nofront / flat 0.5% / 0%) — ค่าปรับใน §2 ใช้ **เฉพาะการตัดสินใจ** ไม่ได้หักจาก NAV

## 1. สมมติฐาน + เหตุผลเชิงเศรษฐศาสตร์
1. **การเปลี่ยนกองคุ้มเมื่อส่วนต่างผลตอบแทนที่คาดว่าคงอยู่ > ต้นทุนเข้า-ออก** — ค่าธรรมเนียมเป็นตัวแปรเดียวที่รู้แน่ล่วงหน้าและไม่มี noise
   ขณะที่ส่วนต่าง SR12 ในอดีตส่วนใหญ่เป็นโชค (Fama & French 2010) และตัวทำนายผลกองอ่อนลง ≥ ครึ่งหลังตีพิมพ์ (Jones & Mo 2021) ·
   ค่าธรรมเนียมทำนายผลกองได้รวมกอง international equity (Kinnel/Morningstar 2016) — หลักฐานรวม "ปานกลาง–แข็ง" ตาม R001
2. ต้นทุนเป็นตัวถ่วงที่วัดได้จริงของ M004-TF-FX: Sharpe 0.894 (ต้นทุน 0) → 0.706 (ค่าธรรมเนียมจริง) · ต้นทุน 185 bp/ปี · ใช้ช่องสับเปลี่ยน 16%
   (อ่านเองจาก `backtest/results/COST_real_fees_summary.csv`) · กองที่เคยถือมีกองใหม่เข้าเฉลี่ย ~3.7 กอง/ไตรมาส จาก 8 และถือเฉลี่ย 2.4 ไตรมาส/กอง
   (สำรวจเอง `scratch/quant_m009_fee_feasibility.py` จาก `M004-TF-FX_weights.csv` — ไม่มี return)
3. **คาดการณ์ ex-ante**: turnover ↓ และต้นทุน bp/ปี ↓ · Sharpe ก่อนต้นทุนไม่ควรลดมาก (ค่าปรับเล็กเทียบการกระจายของ SR12) · ไม่แก้ปี 2022
   (เป็นเรื่อง trend/cash) · ผลส่วนเพิ่มคาดระดับ +0.0x ไม่ใช่ +0.2 → **ไม่คาดว่าถึง 0.95**

## 2. สูตร/อัลกอริทึม (ทุกสิ้นไตรมาส t · ข้อมูล ≤ t)
ขั้น 1–3 เหมือน `tf_model.select_at` เดิมทุกบรรทัด: `u_t`, `sig`, `i_t`, `trend`, `reps = family_representatives(i_t, held_funds=set(held.values()))`
ให้ `H_map = {} if prev_fallback else held` (เหมือนที่ส่งเข้า hysteresis เดิม)

ขั้น 4 — ค่าปรับต่อ family f (ตัวแทน = กอง j, SR12_j, vol52_j จาก `reps[f]`)
```
ถ้า H_map.get(f) == j          : pen_f = 0                       # ถือ class นี้อยู่แล้ว
ไม่งั้น                         : c_j   = (FF_j(t) + BF_j(t)) / 100   # round-trip ช่องทางซื้อ-ขาย (สัดส่วน)
                                  pen_f = c_j × (11/12) / HOLD_YRS / vol52_j
score_f = SR12_j − pen_f
```
- `FF_j(t)`, `BF_j(t)` = `FeeData.rate(j, code, t)` — **ใช้ t (วันตัดสินใจ) ไม่ใช่ e** · กติกาเดียวกับ `analysis/fund_fees.py` ทุกข้อ
  (FEEUH `Actual Value`, แถวล่าสุดที่ As of Date ≤ t, ก่อน snapshot แรกใช้ snapshot เก่าสุด, ค่าว่าง/ติดลบ/> 10 → median: FF 1.5 · BF 0 — ตรวจเองแล้ว)
- `HOLD_YRS = 1` (ค่าคงที่ · §3 ข้อ 2) · `vol52_j` ≥ 0.02 อยู่แล้วจากเกณฑ์ I_t (หารได้เสมอ)

ขั้น 5 — `reps_net = {f: {**reps[f], "signal": score_f}}` → `ranks = rank_families(reps_net)` (tie-break vol52 แล้วชื่อกอง เหมือนเดิม)
ขั้น 6 — `sel = hysteresis_select(reps_net, ranks, H_map)` N=8, K=16 (กองที่ถือและ **อันดับสุทธิ** ≤ 16 ถือต่อ · เติมอันดับสุทธิสูงสุดจนครบ 8)
ขั้น 7 — น้ำหนัก/cap/เงินสด/fallback B0 เหมือนเดิม · `table` ให้บันทึก SR12 ดิบ, pen, score, rank ดิบ และ rank สุทธิ
(แนะนำ: เขียนเป็น wrapper ใน `backtest/` ที่เรียก `analysis/fund_weighting` เดิม — **ห้ามแก้โค้ดแอป**)

## 3. เหตุผลของแต่ละการเลือก (ล็อกก่อนรัน · ไม่ tune)
1. **กองที่ถืออยู่ = 0 · กองใหม่ = FF + BF ของตัวเอง**: เทียบ "สลับ A→B" กับ "ถือ A ต่อ" — ค่าออกของ A (BF_A) ต้องจ่ายไม่ว่าทางไหน (ต่างแค่เวลา)
   จึงหักล้างกัน · ส่วนเพิ่มจริงคือ FF_B (เข้า) + BF_B (ออกในอนาคต) · ระหว่างกองใหม่ด้วยกันเทียบ FF+BF ของแต่ละตัวตรงๆ
2. **หน่วย**: SR12 = ผลตอบแทนส่วนเกิน 11 เดือน (R12-1 − rf×11/12) ÷ vol รายปี → ต้นทุน amortize เป็นรายปี c/HOLD_YRS แล้วคิดในหน้าต่างเดียวกัน
   ×11/12 (แบบเดียวกับที่ rf ถูกหัก) แล้ว ÷ vol52 ให้เป็นหน่วย Sharpe · **HOLD_YRS = 1** = horizon ของสัญญาณ (lookback 12 เดือน, momentum
   ถือได้ ~12 เดือนตามวรรณกรรม) — **ไม่ใช้ระยะถือจริงของ M004-TF-FX** (~0.6 ปีจากข้อ 1.2) เพราะเป็นผลลัพธ์จากช่วงประเมินเดียวกัน (data-dependent)
   · ผล: ค่าปรับแบบนี้ "อ่อน" กว่าการใช้ระยะถือจริง (bias ไปทางเปลี่ยนน้อยกว่าที่ควร) · ขนาดโดยประมาณ: c = 1.5%, vol 0.15 → pen ≈ 0.09
3. **ช่องทางสับเปลี่ยนใน บลจ. เดียวกัน: ไม่ใช้ในการจัดอันดับ (คิดเฉพาะซื้อ-ขาย FF+BF) แต่ใช้ในการคิดต้นทุนจริงตามเดิม (FeeModel cheaper-of)**
   — เหตุผล: (ก) สับได้หรือไม่ขึ้นกับว่ากองไหนถูกขาย ซึ่งขึ้นกับอันดับ → วนกันเอง ต้องเพิ่มขั้นวนซ้ำ (ซับซ้อนโดยไม่จำเป็น)
   (ข) ขนาดเล็ก: median SI 1.07 vs FF 1.5 → ต่างในหน่วย Sharpe ~0.43%×11/12/0.15 ≈ 0.03 · ช่องสับเปลี่ยนใช้แค่ 16% ของยอดใน M004-TF-FX
   (ค) ทิศทาง bias = ประเมินต้นทุนกองค่ายเดียวกันสูงไปเล็กน้อย (conservative) — reviewer ตรวจได้จาก diagnostic §6
4. **ไม่ใช้ score สุทธิเลือก class ภายใน family**: กอง FF = 0 มี 68/570 รหัส (ณ 2025-12) และหลายตัวเป็น class เฉพาะช่องทาง เช่น `KKP *-H-F`,
   `KT-GEQ-I`, `KT-GESG-P`, `-C` → ถ้าใช้ score สุทธิเลือก class โมเดลจะย้ายไป class ที่ลูกค้ารายย่อยอาจซื้อไม่ได้ (ยังไม่ยืนยัน) และปนผลของ
   "การเลือก class" เข้ากับ "การจัดอันดับ" · ค่าปรับใช้ FF/BF ของ class ตัวแทนที่ M004-TF-FX เลือกอยู่แล้ว
5. **ไม่ใช้ TER/FEEMF**: NAV หัก TER แล้ว → หักซ้ำ = นับสองครั้ง (และยังไม่ได้ตรวจว่ามีข้อมูลที่ใช้ได้) → ดู "ต้องให้ผู้ใช้ตัดสินใจ"

## 6. สิ่งที่ขอให้ backtest-validator รัน + เกณฑ์ตัดสิน (ล็อกล่วงหน้า)
**regression ก่อนรัน**: บังคับ pen ≡ 0 → น้ำหนักต้องเท่า `M004-TF-FX_weights.csv` ทุกแถว (max|Δw| = 0) และ Sharpe full = 0.706 เดิม
**ตัวชี้วัดหลัก**: Δ = Sharpe_full(M009-NC) − Sharpe_full(M004-TF-FX) แบบ paired (45 เดือนเดียวกัน) + CI95% block bootstrap
(วิธี/block/seed เดียวกับการเทียบ paired ครั้งก่อน)
- **ผ่าน (ดีกว่า)**: CI ล่าง > 0
- **ผ่านแบบมีเงื่อนไข (เทียบเท่าแต่ถูกกว่า)**: Δ ≥ 0, CI คร่อม 0 **และ** cost bp/ปี (full) < ของ M004-TF-FX → เสนอ reviewer/ผู้ใช้พิจารณาแทนที่
- **ไม่ผ่าน**: Δ < 0 (แม้ต้นทุนลด) → คง M004-TF-FX · ไม่รันซ้ำด้วยค่าอื่น
**รายงานคู่ (ไม่ใช้ตัดสิน)**: Sharpe/CAGR/vol/maxDD ที่ 0%, 0.5%/ข้าง, full, nofront (nofront ใช้น้ำหนักชุดเดียวกัน — โมเดลยังตัดสินด้วย FF+BF เต็ม ติดป้าย)
· **turnover** (ยอดซื้อขากอง/ปี) · cost bp/ปี full · fee เฉลี่ย/ข้าง · สัดส่วนช่องสับเปลี่ยน · กองใหม่ต่อไตรมาส · ระยะถือเฉลี่ยของกองที่เข้า ·
สัดส่วนกองที่เข้าซึ่ง FF = 0 · จำนวนไตรมาสที่ชุดกองต่างจาก M004-TF-FX · การกระจาย pen (median/p90) เทียบช่องว่าง SR12 อันดับ 8 vs 9–16 ·

## 7. ความเสี่ยงที่คาด
- **ผลน้อยจนแยกไม่ออก**: ค่าปรับ ~0.0–0.1 หน่วย Sharpe vs การกระจาย SR12 กว้างกว่ามาก → อาจเปลี่ยนชุดกองแค่ไม่กี่ไตรมาส (CI จะคร่อม 0 แน่นอนเกือบทุกกรณี)
- **ถือกองที่สัญญาณเสื่อม**: กองถือที่อันดับดิบ 17–20 อาจถูกถือต่อ → ถ้า momentum decay เร็ว Sharpe ก่อนต้นทุนลด
- **bias ไปกอง FF = 0** (มักเป็น passive/class เฉพาะช่องทาง/บาง บลจ.) → กระจุกค่าย/ธีม · overfit ต่ำ (1 trial ไม่มีพารามิเตอร์ tune) แต่ DSR แย่ลงตาม n=21
- look-ahead เล็กจากการใช้ snapshot ค่าธรรมเนียม 2023 กับ 5 ไตรมาสแรก (§4)

## 8. สิ่งที่ reviewer ควรตรวจเป็นพิเศษ
1. ค่าปรับใช้ `FeeData.rate(·, t)` ไม่ใช่ e · กองที่ถือ "class เดิม" เท่านั้นที่ได้ 0 (family เดิมแต่ class อื่น = กองใหม่ — เกิดได้เมื่อ class ที่ถือหลุดจาก I_t แล้ว rep เป็น class อื่น · ให้นับว่าเกิดกี่ครั้ง)
2. regression pen ≡ 0 ตรง M004-TF-FX ทุกหลัก · ERC/cap/cash ไม่ถูกแตะ
3. หลัง B0 fallback (`prev_fallback`) ทุกกองถูกปรับเป็นกองใหม่ (ตรงกับ hysteresis เดิมที่ไม่มี held) — นับว่าเกิดกี่ครั้ง
4. ทิศทาง bias ของการไม่คิดช่องสับเปลี่ยนในการจัดอันดับ (§3.3) · และกองที่ใช้ median fallback ใน pen มีกี่ตัว
