## 2. สมมติฐาน + หลักฐาน
1. **Dedupe**: momentum ระดับกองทำให้ top N กระจุก (กอง Nasdaq-100/US tech ของหลาย บลจ. correlation ~0.95) → จำนวนกองจริงเยอะแต่
   "จำนวนเดิมพันอิสระ" น้อย · Grinold (1989) fundamental law: IR ∝ IC·√breadth — breadth ที่ไม่ซ้ำเพิ่ม Sharpe · ERC เพียงอย่างเดียวแก้ไม่ได้เพราะ ERC
   กระจายเสี่ยงเท่ากันระหว่าง "กอง" ไม่ใช่ระหว่าง "ธีม"
2. **overlay แบบ max**: VT ตอบสนองต่อ vol (ช้าในช่วงลงช้าๆ) · TF ตอบสนองต่อทิศ (ช้าในช่วงร่วงเร็ว) → เอาตัวที่ระวังกว่า ภายใต้เพดาน 25%
3. ส่วนที่เหลือเหมือน M004 (hysteresis, class non-D, ERC) — ไม่ tune ค่าใดเพิ่ม

## 3. อัลกอริทึม ณ วัน t
1. U_t, I_t, สัญญาณ SR12, rank family = C1–C4
2. **คัดแบบ C5 + dedupe** (เฉพาะขั้น "เติม"):
   - ρ(a, b) = Pearson correlation ของ return รายสัปดาห์ 52 สัปดาห์ ≤ t (pairwise complete · ต้องมี ≥ 30 สัปดาห์ร่วม · ไม่ถึง → ถือว่าผ่าน)
   - ไล่ family ตาม rank: ตัวแทน j เข้า S ได้เมื่อ **max_{s∈S} ρ(j, s) ≤ 0.85** · ไม่ผ่าน → ข้ามไปตัวถัดไป (ไม่มีการกลับมาดูใหม่ในไตรมาสนั้น)
   - กองที่ **คงไว้** (ขั้นคงไว้ของ C5) ไม่ถูกตัดด้วย dedupe (กัน turnover) — แม้คู่ที่ถือจะ ρ > 0.85 ในภายหลัง
   - ไล่ถึงท้ายรายการแล้ว |S| < N → ถือเท่าที่มี (ถ้า < 4 → fallback B0 ตาม C5)
   - บันทึกจำนวนกองที่ถูกข้ามต่อไตรมาส และ rank สูงสุดที่ต้องไล่ลงไปถึง
3. w = ERC (C8) บน S → cap 25% (C6)
4. c_VT (C9, σ* = 10%) · c_TF (C10) · **c = min(0.25, max(c_VT, c_TF))**
5. น้ำหนักสุดท้าย (1 − c)·w + `__CASH__` = c → `simulate_path` (C7)
