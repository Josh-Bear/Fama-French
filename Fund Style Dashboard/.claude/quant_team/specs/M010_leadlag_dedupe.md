## 1. สมมติฐาน + เหตุผลเชิงเศรษฐศาสตร์
1. **กองหลายกองของธีมเดียวกัน = เดิมพันเดียว**: breadth ที่ไม่ซ้ำเท่านั้นที่เพิ่ม IR (Grinold 1989, อ้างใน M005) · ERC กระจายความเสี่ยงระหว่าง "กอง" ไม่ใช่ "ธีม"
2. **ρ lag-0 ของ NAV กองไทยต่ำเกินจริงจาก NAV ไม่พร้อมกัน** (Scholes–Williams 1977/Dimson 1979; Burns–Engle–Mezrich 1998 — R003 ส่วนที่ 3)
   → dedupe ของ M005 (ρ lag-0) ปล่อยกองซ้ำผ่าน · DIAG (ไม่ได้ตรวจซ้ำเอง): ρ ของกองที่ Trend 25 ถือ median 0.35 → 0.49 เมื่อปรับ, 77% ของคู่เพิ่ม,
   รายเดือน (ไม่โดน async) 0.53 ยืนยันทิศ · คู่ infra KKP GINFRAEQ-H vs ES-GINFRA-A 0.25 → 0.99 · DAOL-KOREAEQ vs PRINCIPAL KEQ 0.65 → 0.99
   · ต้นเหตุหลักดูเป็น "NAV timing ของกอง" (ขึ้นมากใน ตะวันตก–ตะวันตก) มากกว่าเขตเวลา
3. **คาดการณ์ ex-ante (ซื่อตรง)**: กลไกควรลดน้ำหนักรวมของกลุ่มซ้ำ และเพิ่ม DR² เล็กน้อย · ผลต่อ Sharpe **ไม่ชัด ทิศอาจลบ**: หลักฐานเดียวที่มี
   (M005 vs M005-NODD — ต่างกันแค่ dedupe lag-0) Δ = −0.187 CI [−0.519, 0.205] (อ่านจาก `M002-M005_results.md`) · การตัดกองแทนด้วยกองอันดับต่ำกว่า
   = เสีย SR12 · คาด Δ ช่วง −0.2 … +0.1 · **ไม่คาดว่าถึง 0.95** · เป้าของ trial นี้คือ "ไม่แย่ลง + ลดความกระจุกแฝง" ตามที่ R003 แนะนำเกณฑ์

## 2. นิยาม ρ_adj(a, b) ณ t (ล็อก)
ข้อมูล: `ctx = fs.SignalContext(inp.nav_arrays, inp.calendar, t)` · `r_a = ctx.weekly_return_series(a)` (52 return บนกริดสัปดาห์เดียวกัน `ctx.weeks[1:]`, อาจมี NaN)
— **ชุดเดียวกับที่ ERC ของโมเดลใช้** (ข้อมูล ≤ t เท่านั้น)
```
C  = {w : r_a,w และ r_b,w ไม่เป็น NaN} ,  n = |C|
ถ้า n < 30 (TF_COV_MIN_WEEKS = ค่าเดียวกับ M005/ERC) → ρ_adj = NaN → ถือว่า "ผ่าน" (ไม่ตัด) · บันทึก
μ_a, μ_b = ค่าเฉลี่ยบน C ;  x_w = r_a,w − μ_a ,  y_w = r_b,w − μ_b   (w ∈ C)
L  = {w : w ∈ C และ w−1 ∈ C}            # w−1 = สัปดาห์ก่อนหน้าบนกริด (ไม่ใช่ตัวก่อนหน้าใน C ที่บีบรูแล้ว)
Γ0_xy = Σ_{w∈C} x_w·y_w /(n−1)          (ทำเหมือนกันสำหรับ xx, yy)
Γ1_xy = Σ_{w∈L} x_w·y_{w−1} /(n−1)      # cov(x_t, y_{t−1}) — ตัวหาร n−1 เหมือน diag_leadlag.cov_leadlag
S_ab = Γ0_ab + Γ1_ab + Γ1_ba
S_aa = Γ0_aa + 2·Γ1_aa ,  S_bb = Γ0_bb + 2·Γ1_bb      # ความแปรปรวนระยะยาวแบบเดียวกัน (ไม่ใช่ Γ0 ล้วน)
ρ_adj = S_ab / sqrt(S_aa·S_bb)   (×52 ตัดกันเอง) · ถ้า S_aa ≤ 0 หรือ S_bb ≤ 0 → NaN → ผ่าน · clip เข้า [−1, 1]
```
- เหตุผลตัวส่วน: correlation ของ covariance ระยะยาว (Newey–West lag 1 น้ำหนักเต็ม) ต้องหารด้วยความแปรปรวนระยะยาวของตัวเอง — ตรงกับ
  sanity MSCI ใน DIAG (`S[0,1]/sqrt(S[0,0]S[1,1])`) · หารด้วย Γ0 จะดัน ρ ขึ้นเกินจริงเมื่อมี autocorrelation
- ไม่ shrink · ไม่ทำ PSD clip (คู่ละ 2×2; clip ค่าเกิน ±1 แทน) · เทียบแบบ **มีเครื่องหมาย** (ρ_adj > 0.85) ตาม M005
- ต่างจาก DIAG แค่: DIAG ใช้ 8×8 + สัปดาห์ร่วมแบบ listwise + eigen clip → ตัวเลขต่างเล็กน้อย (ตรวจใน §6 regression ข้อ 3)

## 3. อัลกอริทึม ณ t (แทนขั้น 6 ของ `select_at` เดิม)
ขั้น 1–5 เหมือนเดิมทุกบรรทัด: `u_t, ctx, sig, i_t, trend, reps, ranks` · `H = {} if prev_fallback else held`
```
S = {}                                          # family -> FundCode
# (ก) ถือต่อ — เหมือนเดิม ไม่ถูกตัดด้วย dedupe แม้คู่ที่ถือจะ ρ_adj > 0.85
for fam, fc in H.items():
    if fam in reps and ranks[fam] <= K and reps[fam].FundCode == fc: S[fam] = fc
# (ข) เติม — เทียบกับทุกกองใน S ขณะนั้น (ทั้งที่ถือต่อและที่เพิ่งเติม)
K_fill = min(K, จำนวน family)                   # ไล่ได้ไม่เกินอันดับ 16 (หรือจนหมดรายการถ้ามี family < 16)
for fam in families เรียงตาม rank (1..K_fill):
    if |S| >= N: break
    if fam in S: continue
    j = reps[fam].FundCode
    ρs = [ρ_adj(j, s) for s in S.values()]  (ข้าม NaN)
    if any(ρ > 0.85 for ρ in ρs): บันทึก skip (fam, j, rank, กองใน S ที่ชน, ρ_adj, ρ_lag0 Pearson เทียบ); continue
    S[fam] = j
# (ค) จำนวนกอง
|S| = 8 → ปกติ · 4 ≤ |S| < 8 → ถือเท่าที่ได้ (ERC + cap 25% เดิม · 4 กอง = 25% เท่ากัน) · |S| < 4 → fallback B0 เดิม
```
- skip ทั้ง family (ไม่ลอง class อื่นใน family เดียวกัน — class ต่างกันแทบเป็นกองเดียว) · ไม่มีการกลับมาดูกองที่ข้ามซ้ำในไตรมาสเดียวกัน
- **ทำไมจำกัด K_fill = 16 ทั้งที่การเติมเดิมไม่มีขีด**: กองอันดับ > K ที่ถูกเติมจะหลุดเกณฑ์ถือต่อทันทีไตรมาสถัดไป (ถ้าอันดับไม่ขึ้น) = ซื้อแล้วขาย
  ต้นทุน ~2× ค่าธรรมเนียม · ใช้ K ที่ลงทะเบียนแล้วจึงไม่มีพารามิเตอร์ใหม่ · **การเติมเดิมไม่เคยเกินอันดับ 16 อยู่แล้ว** (กองถือต่อ ≤ 8 กองล้วนอันดับ ≤ 16
  → อันดับ 1..16 เหลือว่าง ≥ 16 − |kept| ≥ 8 − |kept| ที่ต้องเติม) → ไม่กระทบ regression
- หลัง fallback B0 (H = {}) ทุกกองผ่านขั้น (ข) → dedupe มีผลเต็มที่ · ERC/cap/เงินสดเหมือนเดิม
- แนะนำ: wrapper `backtest/run_m010.py` เรียก `analysis/*` เดิมแบบ read-only (คัด `select_at` มาแทนเฉพาะขั้นเลือก) — **ห้ามแก้โค้ดแอป**

## 7. ความเสี่ยงที่คาด
- **path dependence (ใหญ่สุด)**: M009 เปลี่ยน ~1 กอง/ไตรมาสจากไตรมาสแรกแล้วสืบทอดผ่าน hysteresis 14/15 ไตรมาส, Δ −0.20 CI ไม่คร่อม 0 → skip ครั้งเดียว
  ก็เปลี่ยนทั้ง path ได้ · Δ ที่ได้สะท้อน "โชคของ path" ปนกลไก → ห้ามอ่าน Δ เป็นมูลค่าของ dedupe อย่างเดียว
- **noise ของ ρ_adj จาก 52 จุด** (DIAG ข้อจำกัด): ตัวประมาณ 3 เทอมแปรปรวนกว่า lag-0 · ใกล้ 0.85 อาจพลิกไตรมาสต่อไตรมาส → เข้า-ออก · autocorrelation
  จริงของ return (ไม่ใช่ async) ก็ดัน ρ_adj ได้ · ป้องกันบางส่วนด้วยไม่ตัดกองถือต่อ
- **เสีย SR12**: กองแทนอันดับต่ำกว่า + อาจหลุด K เร็ว → turnover/ต้นทุน ↑ · ถ้า momentum ของธีมเป็นตัวทำเงิน (infra ปี 2025) การตัดจะลด return
- **กลไกอาจอ่อน**: กองซ้ำที่ "ถือต่อ" ไม่ถูกตัด → G_t ลดช้า · ERC ยังใช้ Σ lag-0 (ยังให้น้ำหนักเกินกับกลุ่มที่เหลือ)
- overfit ต่ำ (ไม่มีพารามิเตอร์ใหม่ยกเว้นเกณฑ์ตัดสิน −0.10) แต่ไอเดียถูกเลือกหลังเห็น DIAG ของ holdings Trend 25 (selection bias ระดับไอเดีย) · DSR ลดตาม n = 22

1. ρ_adj ใช้ return ≤ t, กริดสัปดาห์ (lag ข้ามรูไม่ได้), ตัวส่วนเป็น S_aa/S_bb, เทียบกับ **ทุกกองใน S** ณ ขณะนั้น, กองถือต่อไม่ถูกตัด
2. regression threshold 1.01 ตรงทุกหลัก · ERC/cap/cash/fee ไม่ถูกแตะ · ไล่ไม่เกินอันดับ 16
3. แยก Δ เป็นไตรมาสที่ skip จริง vs สืบทอด — ถ้า Δ มาจากไตรมาสเดียว/กองเดียว ให้ระบุ (เหมือน M009)
4. skip ที่ ρ_lag0 ≤ 0.85 แต่ ρ_adj > 0.85 (= ส่วนที่ M005 ทำไม่ได้) มีกี่ครั้ง · skip ที่เป็นธีมเดียวกันจริง (infra/เกาหลี) vs ดูเหมือนบังเอิญ
5. ไม่มีการเลือกกองด้วยชื่อ/ธีมจากความรู้ภายนอก · ตัวเลข DIAG ที่อ้างใน spec นี้ไม่ได้ตรวจซ้ำโดย modeler

## 9. ต้องให้ผู้ใช้ตัดสินใจ
1. อนุมัติ 1 trial (trial ที่ 22) ตามเกณฑ์ §6 — รวมเกณฑ์ "มีเงื่อนไข" Δ ≥ −0.10 ที่ modeler ตั้ง (ยอมรับ / ขอเข้มกว่า เช่น Δ ≥ 0 เท่านั้น)
