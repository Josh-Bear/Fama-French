## นิยาม (ล็อกก่อนรัน ตาม R004 #1)
- t = 16 สิ้นไตรมาส 2022-03-31..2025-12-31 · family = ตัวแทนใน `data_access.tf_live(t)["table"]` (155 ที่ 2022-03 → 327 ที่ 2025-12) · ข้อมูล ≤ t เท่านั้น
- รายสัปดาห์ expanding (≥ 52 สัปดาห์; จริง 65–262) · NAV/ดัชนี as-of ≤ วันนั้น (tol 10 วัน) · weekly return |r| > 50% ตัดเป็น NaN
- ดัชนีคู่ = R² สูงสุดของ `r_f ~ 1 + x_t + x_(t-1)` จาก 28 ดัชนี THB (18 country รวม ACWI + 10 sector) · alpha = intercept ของ `r_f = α + β0 x_t + β1 x_(t-1) + γ·dUSDTHB + e` (×52) · TE = sd(e)·√52 · IR = α/TE
- USDTHB: **มี**ใน `MACRO_FACTOR.csv` (ใช้ regressor lag 0 อย่างเดียว) · "excess ดิบ" (BAR) = mean(r_f − r_idx)·52
- alpha อนาคต (t, t+4Q]: ดัชนีคู่เดิม ณ t · **หลัก** = ประมาณ α ใหม่ในหน้าต่าง (Dimson+FX, ≥ 40 สัปดาห์) · robust = beta/γ ตรึงจาก t · IC เฉพาะ t ที่ t+4Q ≤ 2025-12-31 → **12 ไตรมาส (2022-03..2024-12)** (NAV ปี 2026 มีรู)
- IC = Spearman ข้ามกองต่อไตรมาส · t-stat = mean/(sd/√12) แบบ naive และ Newey-West lag 3 · **หน้าต่าง 4Q ซ้อนทับ 75% → t-stat เกินจริง** ใช้ดูทิศ ไม่ใช่ความมีนัยแท้ (จริงๆ มีหน้าต่างไม่ซ้อนกันแค่ 3 ชุด)

## ข้อ 2 — Persistence (IC ต่อ α อนาคตที่ประมาณใหม่)
| ทำนายจาก | Universe (n≈155–260/ไตรมาส) IC · t naive/NW | Top-16 SR12 (n=16) IC · t naive/NW |
|---|---|---|
| α ณ t | **0.266** · 5.8 / 4.6 (บวก 11/12 ไตรมาส) | **0.306** · 4.5 / 4.4 |
| IR ณ t | 0.242 · 6.0 / 4.9 | 0.313 · 5.1 / 5.2 |
| excess ดิบ (BAR) | 0.257 · 5.8 / 4.4 | 0.283 · 3.7 / 3.2 |
| SR12 | 0.197 · 4.4 / 4.2 | 0.129 · 2.1 / 4.3 (NW ไม่น่าเชื่อ) |
| α ไม่ใส่ FX | 0.279 | 0.358 |

- robust: α→α_fwd(β ตรึง) 0.315; α→BAR อนาคต 0.214; หักค่ากลางภายในดัชนีเดียวกัน (กลุ่ม ≥ 3 กอง) α→α_fwd **0.259** (t 10.8, ทุกไตรมาสเป็นบวก) → ไม่ใช่แค่ผลต่างระหว่างดัชนี
- ชุดไม่ซ้อนทับ (ไตรมาส i, i+4, i+8): IC ของ α = 0.343 / 0.239 / 0.268 / 0.212 ตาม offset 0–3 (สม่ำเสมอ)
- **แต่ IC รายไตรมาสจางลงท้ายช่วง**: 2024-03 0.40 → 2024-06 0.16 → 2024-09 0.07 → **2024-12 −0.12** (หน้าต่างอนาคต = ปี 2025)
- α ซ้ำซ้อนกับ SR12 ส่วนหนึ่ง (cross-sectional rank corr เฉลี่ย 0.43) · Fama-MacBeth rank(α_fwd) ~ rank(α)+rank(SR12): ค่าสัมประสิทธิ์ α 0.218 (t 4.6), SR12 0.107 (t 2.4) → α มีข้อมูลเพิ่มจาก SR12 ในแง่ "alpha อนาคต"
- **สำคัญ: persistence ของ α ไม่ได้แปลว่าทำนาย return รวมได้** IC ต่อ return สะสม 4Q ข้างหน้า: universe α 0.090 (t 2.9), SR12 0.152 (t 1.7) · top-16: α **−0.084**, SR12 −0.096 (ทั้งคู่ไม่มีนัย; n=16)

## ข้อ 6 — คำตัดสิน (ข้อเสนอ การตัดสินใจเป็นของผู้ใช้)
**α ทำนาย α อนาคต "ได้ค่อนข้างชัดแต่จางลง"**: IC ~0.27 (universe) และ ~0.31 (top-16) สม่ำเสมอ 3 ชุดที่ไม่ซ้อนทับและภายในดัชนีเดียวกัน — **แต่** (ก) 12 ไตรมาส/3 หน้าต่างอิสระ t-stat ที่เห็นเกินจริง (ข) ล่าสุด (หน้าต่างปี 2025) IC ติดลบ (ค) ส่วนใหญ่น่าเป็น "คุณภาพพาหนะ" (ค่าธรรมเนียม/hedge/benchmark fit) ซึ่ง persist ตามธรรมชาติ ไม่ใช่ฝีมือ และ **(ง) ไม่ส่งต่อไปเป็นการทำนาย return รวม** (IC 0.09; ใน top-16 ≈ 0/ติดลบ)
**ข้อเสนอ**: ใช้ α เป็น "ตัวชี้วัดคุณภาพสำหรับอธิบายลูกค้า" ได้เลย (ไม่ต้อง trial) · trial R004 #1 (กรองขาเข้า median) **ยังไม่คุ้มถ้าจุดประสงค์คือยก Sharpe** เพราะหลักฐานใน diagnostic นี้ไม่ชี้ว่า α ช่วย return · ถ้าผู้ใช้ต้องการเพียงหลักฐานว่า "ไม่ทำให้แย่ลง" ทำได้ 1 trial แต่คาดผลอยู่ในสัญญาณรบกวน

## ข้อจำกัด / สิ่งที่ตีความเอง
1. เลือกดัชนีด้วย R² ของ Dimson (ไม่ใส่ FX) — ไม่ได้ทดลองวิธีอื่น (ตาม Mateus: ไม่เลือกหลายวิธี) · 2. γ_FX median −0.6 ในกองที่ไม่ระบุ hedge ต้องตรวจเพิ่ม (ผล IC ไม่ต่างเมื่อไม่ใส่ FX: 0.279 vs 0.266) · 3. return รายสัปดาห์ของกองที่ NAV ค้างเป็นศูนย์/เหลื่อมเวลา — Dimson ลดแต่ไม่หมด · 4. survivorship: α อนาคตคำนวณได้เฉพาะกองที่มี NAV ≥ 40 สัปดาห์ในหน้าต่าง · 5. top-16 มี n=16 ต่อไตรมาส IC ผันผวนสูง · 6. ปี 2025 ใช้เป็นเป้าหมายอนาคตได้ผ่านเฉพาะ t ≤ 2024-12 (2026 ไม่ใช้)
