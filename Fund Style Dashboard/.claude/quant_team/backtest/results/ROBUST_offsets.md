## 2. วิธีทำและการตีความของ validator

- ไตรมาสเหมือนเดิม (15 การตัดสินใจ/offset) เปลี่ยนเฉพาะเดือน: t = **วันทำการสุดท้ายของเดือนนั้นในปฏิทินดัชนี** (offset 0 ตรงกับ `quarter_ends` เดิมทุกวัน) · e = วันทำการที่ 2 หลัง t (เดิม) · สัญญาณ SR12/vol52/ERC/ACWI 3-6-12 เดือน/hurdle rf/Quality/เลือกกองตลาดเงิน คำนวณใหม่ ณ t ใหม่ด้วย `r9.prepare`/`r11`/`r12`/`r13`/`r15` เดิม (NAV ≤ t) · hysteresis เริ่มว่างทุก offset
- วันตัดสินใจ: offset 0 = 2022-03-31 … 2025-09-30 · offset 1 = 2022-04-29 … 2025-10-31 · offset 2 = 2022-05-31 … 2025-11-28 (การตัดสินใจสุดท้ายของ offset 1/2 ถือแค่ 2/1 เดือนก่อน 2025-12-31)
- **ช่วงวัดผลร่วม**: ฐาน = มูลค่าพอร์ตสิ้นเดือน **2022-06-30** (ทุก offset ลงทุนแล้ว; offset 2 เข้าตลาด 2022-06-02) → ผลตอบแทนรายเดือน **ก.ค. 2022 – ธ.ค. 2025 = 42 เดือน** เท่ากันทุก offset/โมเดล · ช่วงนี้ตัด เม.ย.–มิ.ย. 2022 (ช่วงเสียหนัก) ออกจากช่วงเดิม 45 เดือน → **Sharpe offset 0 ในช่วงร่วม ≠ 0.765** (ดูตาราง §3 คอลัมน์ 'ช่วงเดิม')
- tranche = ถือ 1/3 ต่อ offset แบบ buy-and-hold จากฐาน 2022-06-30 (ค่าเฉลี่ยของมูลค่าที่ปรับฐาน=100) · ต้นทุนของแต่ละ tranche คิดแยก (ไม่มี netting ข้าม tranche → ไม่ได้ประโยชน์จากการหักล้างคำสั่ง) → เป็นตัวแทน 'ไม่ขึ้นกับเดือน' ไม่ใช่พอร์ตเดียวที่ดำเนินการได้จริงพอดี
- Sharpe = excess รายเดือนเฉลี่ย ×12 ÷ (sd(r)×√12), rf รายเดือนจากเส้นนโยบายจริง · A − B: paired block bootstrap (`r11.paired_real`, block 3, 2000, seed 0)
