### 1.3 'Actual Value' คืออะไร — อ่านจาก schema PDF + ข้อมูลดิบ

### 2.4 edge case

1. **ขายเป็นเงินสด / ซื้อกองจากเงินสด (GC75 ปรับสัดส่วนหุ้น)**: คิดเฉพาะขากอง ✓ — ตัวอย่าง GC75 k=10 (2024-10-02) หุ้น 1.00→0.50: ขาย 0.639 / ซื้อ 0.139, ต้นทุนรวม 3.1bp (BF≈0 จึงถูกมาก, ส่วนใหญ่เป็นขาออก) · k=4 (2023-04-04) หุ้น 0.504→0.75 ซื้อ 0.619 → จ่าย FF 69.6bp · ผลคือ **ต้นทุนไม่สมมาตร: ลดหุ้นถูก (BF≈0), เพิ่มหุ้นแพง (FF≈1.5%)** ซึ่งเป็นพฤติกรรมที่ถูกต้องตามข้อมูล
2. **เงินสดไม่เสียต้นทุน**: สมมติว่าเงินสด = เงินฝาก/ตลาดเงินที่ซื้อขายฟรี (ไม่ใช่กองตลาดเงินของ บลจ.) — สมมติฐานที่สมเหตุผลแต่ไม่ได้ตรวจกับช่องทางจริง
3. **drift ก่อน rebalance**: คิดจาก NAV ล่าสุด ≤ e ของกองที่ถือ (mark) ✓ ส่วนราคาซื้อใช้ NAV แรก ≥ e (≤10 วันทำการ) — ต้นทุนเป็นสัดส่วนของมูลค่า drift ก่อนหักต้นทุน
4. **ต้นทุนถูกหักเป็นสัดส่วนของมูลค่าพอร์ตรวม แล้วลดทุกสินทรัพย์เท่ากัน (value×(1−cost))** แทนที่จะหักจากยอดซื้อ/ขายจริง — เงินสดจึงถูกลดไปเล็กน้อยด้วย · ผลกระทบเล็กมาก (ลำดับ cost×เงินสดสัดส่วน ≤ ~0.1bp/entry) ไม่แก้
