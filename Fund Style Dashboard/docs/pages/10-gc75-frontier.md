## หน้านี้ทำอะไร
ดูว่ากองที่โมเดล **M019** ถือจริง ณ สิ้นไตรมาส อยู่ตรงไหนเทียบกับ efficient frontier ของกองชุดเดียวกัน — 4 ไตรมาส (สุ่มแบบคงที่) = 4 กราฟ (2 × 2)
- **M019** = หุ้น 3 กอง: อันดับ 1 ตาม SR12′ (rf จริง · เกณฑ์คุณภาพ AUM ≥ 100 ล้าน + อายุ ≥ 2 ปี) แล้วเติมกองที่ ρ_adj (lead-lag) สูงสุดกับกองที่เลือกแล้ว
  ต่ำสุด จากอันดับ ≤ 9 · ถือต่อถ้ายังอยู่อันดับ ≤ 9 · ERC เพดาน 40% ของส่วนหุ้น
- สัดส่วนหุ้น = **GC75** (100/75/50/25% ตาม ACWI 3/6/12 เดือนเทียบดอกเบี้ย) · ส่วนที่เหลือ = **กองทองที่ AUM ใหญ่สุด** (kind G · ไม่มี → กองตลาดเงิน kind F)
- ขาตั้งรับ (≤ 1 กอง) อยู่ในทุกพอร์ตด้วยน้ำหนักจริง (**ล็อก**) · ไตรมาสหุ้น 100% ไม่มีขาตั้งรับ
- เทียบ **max Sharpe กับ ERC ของโมเดล**: ตารางตัวเลขคาดหวัง ณ t + bar chart น้ำหนักกองหุ้นคู่กัน (`viz.weights_compare_bar`)

ไตรมาสที่สุ่มได้ (`GC75_FRONTIER_SEED` · `GC75_FRONTIER_N_QUARTERS = 4`): **2022-09-30** (หุ้น 25% + ทอง 75%) · **2024-03-29** (หุ้น 100%) ·
**2024-09-30** (หุ้น 50% + ทอง 50%) · **2025-09-30** (หุ้น 100%)

## วิธีคำนวณ
| ขั้น | กติกา |
|---|---|
| μ | ค่าเฉลี่ย weekly return 52 สัปดาห์ ≤ t × 52 (สิ่งที่เห็นได้ ณ วันตัดสินใจ · ไม่ใช่ผลหลังซื้อ) |
| Σ | × 52 · block กองหุ้นบนสัปดาห์ที่กองหุ้นทุกกองมีข้อมูล (≥ 30 · ชุดเดียวกับ ERC) · ขาตั้งรับ variance/covariance คู่ต่อคู่บนสัปดาห์ที่มีข้อมูล (กองทองบางไตรมาสขาด 3 สัปดาห์ · ไม่ PSD → ใช้สัปดาห์ร่วมทั้ง matrix) · block กองหุ้น = Ledoit-Wolf เป้า **constant correlation เฉพาะกองหุ้น** · แถว/คอลัมน์ขาตั้งรับ = sample variance/covariance · ตรวจ PSD ทุกครั้ง |
| กริด | **เฉพาะส่วนหุ้น**: หุ้น 3 กอง กองละ 0–40% ของส่วนหุ้น ทีละ **1%** → **231 ชุด** (`composition_grid(3, 0.01, 0.40)` · ผู้ใช้เปลี่ยนจาก 5%/15 ชุด 2026-10-14) × สัดส่วนหุ้นจริง · ขาตั้งรับล็อกที่น้ำหนักจริง · เพดานกริด `GC75_FRONTIER_MAX_W` แยกจากเพดาน ERC ของโมเดล `GC75_FRONTIER_MODEL_CAP` (40%) |
| frontier | จุดที่ไม่มีพอร์ตอื่นให้ผลตอบแทนสูงกว่าที่ความเสี่ยงเท่ากัน (`pareto_mask`) |
| MVP | พอร์ตความเสี่ยงต่ำสุดของกริด |
| max Sharpe | (μ − rf) ÷ σ สูงสุดบน frontier · rf = ดอกเบี้ยนโยบาย ธปท. ที่มีผล ณ t |
| ERC (กติกาโมเดล) | `fund_weighting.risk_parity_weights` + `apply_cap(40%)` ของกองหุ้น × สัดส่วนหุ้นจริง + ขาตั้งรับ = **พอร์ตที่ M019 ถือจริง** (ตรงทุกไตรมาส < 1e-15) |

**ทำไม Σ ไม่ใช้ Ledoit-Wolf แบบที่ ERC ใช้** — sklearn `LedoitWolf` shrink เข้าหา μI ทำให้ vol ของกองที่ vol ต่างจากค่าเฉลี่ยมาก
(กองตลาดเงิน ~0.01%) ถูกดึงจนเพี้ยน · เป้า constant correlation คง variance ของแต่ละกอง shrink เฉพาะ correlation · ใช้เฉพาะ block กองหุ้น
(ใส่ขาตั้งรับที่ corr กับหุ้นต่ำจะดึง correlation ระหว่างกองหุ้นลงตาม) · กองหุ้นที่ variance ≈ 0 → error แทนการตกไปใช้เป้า μI เงียบๆ

## ⚠️ ข้อควรระวัง
1. **ไม่ใช่คำแนะนำการลงทุน** — เป็นการวาดพื้นที่ความเสี่ยง-ผลตอบแทนจากข้อมูลย้อนหลัง 1 ปี
2. เพดาน 40% × 3 กอง บังคับให้ทุกกอง ≥ 20% → frontier สั้น (231 พอร์ตในกรอบแคบ) · μ จาก 52 สัปดาห์คลาดเคลื่อนสูง → max Sharpe มักชนเพดาน 40%
3. ERC ไม่ได้ใช้ μ จึงไม่ควรอยู่บน frontier ที่สร้างจาก μ ย้อนหลัง — ระยะห่างไม่ใช่ความผิดพลาดของโมเดล
4. Sharpe ของพอร์ตที่ความเสี่ยง < 0.5% ไม่แสดง
5. correlation รายสัปดาห์ของกองไทยต่ำเกินจริงจาก NAV ไม่พร้อมกัน (ดูข้อ 3 ของหน้า 9) → frontier ดูกระจายความเสี่ยงได้ดีเกินจริง
