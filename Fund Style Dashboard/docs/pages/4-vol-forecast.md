# 🔮 หน้า 4 — Vol Forecast

**ไฟล์:** `pages/4_🔮_Vol_Forecast.py` · โมเดลอยู่ใน `analysis/vol_forecast.py`

## หน้านี้ทำอะไร
ทำนาย **ความผันผวน (annualized volatility) ของดัชนี MSCI ล่วงหน้า 21 วันทำการ** แล้วเทียบว่าโมเดลไหนแม่นกว่า
ระหว่าง **EWMA** (baseline) กับ **GARCH(1,1)** โดยพิสูจน์ด้วย walk-forward backtest

> ⚠️ หน้านี้เป็น **ระดับดัชนี ไม่ใช่ระดับกองทุน** และ**แยกอิสระจาก pipeline กองทุน** ทั้งหมด
> (ไม่ใช้ `results.csv`/`coefs.csv` เลย ใช้แค่ไฟล์ MSCI)

## ทำไมต้องแยกจากหน้า 1-3
ข้อมูลดัชนีสะอาดกว่ามาก (รายวันครบ ไม่มี NAV gap) และมีแค่ 28 series เทียบกับ 313 กอง
→ ได้ผลที่เชื่อถือได้ก่อน แล้วค่อยต่อยอดไประดับกองทุนในอนาคต (ยังไม่ทำ)

## 3 ส่วนในหน้า

### 📍 A — Forecast ล่าสุด (3 metric card)
| การ์ด | ความหมาย |
|---|---|
| Realized vol (21d ที่ผ่านมา) | vol **จริง**ที่เพิ่งเกิดใน 21 วันล่าสุด |
| EWMA forecast (→21d) | EWMA ทำนาย 21 วันข้างหน้า |
| GARCH forecast (→21d) | GARCH ทำนาย 21 วันข้างหน้า (ติดป้าย `fallback→EWMA` ถ้า fit ไม่ผ่าน) |

ตัวอย่าง ACWI: realized 11.8% · EWMA 12.1% · GARCH 13.5% → ทั้งคู่มองว่าความผันผวนจะขยับขึ้นเล็กน้อย

### 📈 B — Walk-forward backtest (line chart)
แต่ละจุด = 1 หน้าต่าง 21 วัน ตลอด 2022→2026
- 🔴 **แดงทึบ = realized (ค่าจริง)**
- 🟡 เหลืองประ = EWMA ทำนาย
- 🔵 น้ำเงินประ = GARCH ทำนาย

ใช้ดูว่าโมเดลตามความจริงทันแค่ไหน — จะเห็นว่าทั้งคู่จับ spike ได้แต่มี lag เล็กน้อย (เพราะ forecast ใช้ข้อมูลถึงต้นหน้าต่างเท่านั้น)

### 🏆 C — Model comparison (ตาราง)
เทียบ EWMA vs GARCH ทั้ง **ทุกดัชนีใน scope นั้น** และ **เฉพาะดัชนีที่เลือก**

| Metric | คำนวณบน | ต่ำ = ดีกว่า |
|---|---|---|
| RMSE / MAE | vol | ✅ |
| QLIKE | variance | ✅ |

> "ทุก country (18)" / "ทุก sector (10)" คำนวณแยกตาม scope ไม่ปนกัน เพราะลักษณะความผันผวนต่างกัน

## ผลที่ verify แล้ว
- **57 หน้าต่าง/ดัชนี** ครบทั้ง 28 ตัว · **GARCH fit สำเร็จ 100% ไม่มี fallback เลย**
- **GARCH ชนะ EWMA เล็กน้อยในภาพรวม**: RMSE 0.0629 vs 0.0655 · QLIKE −2.503 vs −2.482
- แต่**ไม่ชนะทุกดัชนี** — เช่น TAIWAN GARCH ดีกว่าชัด ส่วน USA EWMA สูสี/ดีกว่านิดหน่อย
- ตัวอย่างระดับ vol: USA realized เฉลี่ย 15.8% (GARCH ทำนาย 16.5%) · TAIWAN 24.4% (GARCH 23.3%)

## ข้อควรระวัง
1. **sample เล็ก** — 57 หน้าต่าง/ดัชนี ไม่เยอะทางสถิติ ควรอ่านผลเป็น "ทิศทาง" ไม่ใช่ข้อสรุปเด็ดขาด
2. **ไม่ครอบคลุม regime วิกฤตรุนแรง** — ข้อมูลแค่ 2021-2026 ไม่มีเหตุการณ์แบบ 2008 หรือ มี.ค. 2020
3. **ไม่ winsorize ผลตอบแทนดัชนี — ตั้งใจ** ต่างจาก pipeline กองทุนที่ winsorize 1–99%
   เพราะงาน vol forecasting ต้องการให้โมเดล react ต่อ tail event จริง (เช่นช่วง MSCI_KOREA ผันผวนสูง มิ.ย. 2026 ที่ return วันเดียว +22% — ตรวจแล้วเป็น regime จริงไม่ใช่ data error)
   ข้อแลกเปลี่ยน: ถ้ามี data error จริงจะไม่มีตัวกัน
4. **ระดับดัชนี ไม่ใช่ระดับกองทุน**
